# 이야기 구조 참고 뱅크 V1.0 — V13.9 연동 · 2026-10-20 작법 역할 보완판

이 파일은 메인 프롬프트의 구조 선택·설계를 돕는 참고 자료다. 진행 순서·사용자 확인·분량·문체·인트로 규격은 01번 파일이 정한다.

[V13.9 이야기 완성도 보완]
전체 설계는 주 작법 1개+필요한 보조 0~1개다. 기본 전체 후보는 STR01·03·04·05·07·08·09이며 STR10 인과·STR06 연결 요약·STR02 주요 장면 점검은 모든 작품의 공통 기준으로 사용하고 보조 개수에 세지 않는다. 사용자가 지정한 작법과 진행 중 작품의 확정 선택은 보존한다. CH01~CH02에 주인공을 응원할 구체적 행동과 감수한 대가를 넣는다. CH16~CH20에는 초반 선택과 대비되는 마지막 행동·결과를 보여 준다. 성장·신념 유지·비극·관계 변화는 장르에 맞게 선택하고 교훈 설명·상벌만으로 대신하지 않는다. 실제 근거는 기존 story_facts의 story_quality에 기록한다. 상세 규칙은 01번의 V13.9 보완 절을 따른다.

## 고정 틀: 5막 20챕터 — 2026-10-14 최종 적용

모든 새 작품은 **5막 × 막당 4챕터 = 총 20챕터**로 작성한다. 별도 인트로 대사와 본편 텍스트 합계 목표는 **35,000자**로 고정하며 실제 완성 글자수의 최소 하한으로 사용한다. 매 작품마다 길이 선택지를 묻지 않는다. 60초 인트로는 별도 도입 구간이고, 본편의 20챕터에 한 챕터로 추가 계산하지 않는다. 막·챕터 표시는 내부 기획과 진행 기록에만 쓰며 최종 낭독용 대본에는 출력하지 않는다.

**변화 요소는 10가지 작법 중 1~2개다.** `주 작법 1개 + 필요할 때만 보조 작법 1개`를 고른다. 기존 primary_structure/STR 코드 표기는 이 선택을 기록하는 내부 필드이며 고정 5막을 바꾸는 지시가 아니다. 시드 필드의 3막, Save the Cat의 15비트, 트루비의 22단계는 아래 20챕터 안에 대응시킨다. 두 작법이 같은 역할을 중복하면 하나만 쓴다. 구조 이름만 바꾼 동일 줄거리는 보완한다.

**최종 목표는 서로 다른 이야기 경험이다.** 기획 때 주 정서 1개와 결말 방식 1개를 정한다. 통쾌함·애틋함·신비로움·따뜻함·씁쓸한 깨달음 등은 후보이며 장르와 인물 선택에 맞춰 고른다. 같은 장르여도 사건 원인·시도 방식·반전의 의미·마지막 선택·남는 감정이 달라지게 한다. A~D는 결말 감정과 해결 방식의 차이를 한 줄씩 표시한다. 통쾌한 처벌·신분 폭로·재물 보상으로 모든 이야기를 마무리하지 않는다. 신비로운 여운도 중심 질문의 미회수를 뜻하지 않는다.

역할은 고정하고 역할을 채우는 사건과 감정은 바꾼다. CH10의 의미 전환은 반드시 최고조·대승·대패일 필요가 없다. 프라이탁을 고르면 앞서 생긴 절정의 결과를 후반에 처리할 수 있고, CH17~18에 두 번째 절정을 억지로 만들지 않는다. 시드 필드의 설정은 1막, 대립은 2~4막, 해결은 5막 안에 대응시키되 작품의 실제 사건으로 근거를 남긴다. STR08의 `2막 진입·3막 진입`은 작법의 비트 이름이며 운영상 2막·3막과 같은 번호가 아니다.

4-C에서 `막 / CH / 고정 역할 / 사건 E / 선택한 작법 기능 / 진입→이탈 상태 / 감정 변화 / 회수할 질문`을 설계한다. 5단계에서는 이 배치를 유지한 채 실제 인트로 글자수를 빼서 20개 최소 할당량을 계산한다. 개별 챕터 역할·순서·개수를 바꿔 분량을 맞추지 않는다. 한 챕터에는 인과가 이어지는 핵심 장면 1~3개를 충분히 쓰고, 20챕터라는 이유로 100개 이상의 짧은 장면을 강제하지 않는다.

이 고정 틀은 구형 5·7·9챕터 선택 규칙보다 우선한다. 이전 완료 원고는 보존한다. 진행 중인 구형 작품도 이번 틀로 바꿔 달라는 요청이 있을 때만 별도 수정본을 만들며, 단순 `계속`은 확정된 기존 진행을 이어 간다.

## 자료의 범위

사용자가 제공한 `12035.mp4`의 약 16분 전후 화면에 등장하는 다섯 조합에서 다음 열 가지 작법을 확인했다. 시드 필드 3막＋Story Grid 5계명, 프라이탁 피라미드＋기승전결, 댄 하먼 Story Circle＋Story Spine, 트루비 22단계＋Save the Cat 감정 비트, 축소형 영웅의 여정＋아리스토텔레스 구조다.

이 목록은 영상에서 제시한 작법 모음이다. 보편적인 인기 순위나 조회수 보장 공식으로 표현하지 않는다. 영상 제작자의 비공개 프롬프트를 복원한 자료도 아니다. 아래 선택 기준·야담용 축약·예시·검사 방식은 이 생성기를 위해 새로 설계했다. Save the Cat은 이 자료에서 **감정 비트**를 뜻하며, 10개 이야기 장르 목록과 구분한다.

## 선택과 역할 분담

- 한 작품에 주 작법 1개를 사용하고 실제로 필요한 보조 작법만 1개 추가한다. 총 1~2개이며 두 개면 서로 다른 STR 코드를 고른다. 하나로 충분하거나 사용자가 하나만 지정하면 보조는 `없음`이다.
- 고정 5막 20챕터의 역할 안에서 주 작법은 사건이 진행되고 의미가 전환되는 방식을 정한다. 보조 작법은 인과관계·선택과 대가·감정 변화·반전의 이해 중 필요한 한 역할을 맡는다. 보조 작법 때문에 두 번째 전체 줄거리를 만들지 않는다.
- A~D의 소재·주인공 결핍·마지막 선택·관객에게 줄 감정에 맞춰 고른다. 장르명만 보고 고정하거나, 열 가지를 순번·무작위로 돌리지 않는다. 적합성이 비슷하면 최근 사용이 적은 조합을 우선한다. 최근작을 읽을 수 없으면 사용 이력을 만들어 내지 않는다.
- 두 작법이 같은 기능을 맡으면 역할을 조정하거나 보조를 다시 고른다. 댄 하먼과 영웅의 여정을 동시에 전체 전개로 적용하는 식의 중복을 피한다.
- 구체적인 사건표는 E01부터 시간순으로 번호를 붙인다. 작법의 단계 수, 사건표 행 수, 챕터 수는 서로 다를 수 있다. 하나의 사건이 여러 설계 기능을 수행해도 된다.
- 위 열 가지 가운데 적합한 후보 2개를 내부 비교한 뒤 주 구조 1개를 고른다. 종전의 다섯 조합을 기본값처럼 반복하지 않는다. 보조는 부족한 기능과 적용 E를 먼저 정한 뒤 고른다. 주 구조와 보조를 같은 순서의 두 줄거리로 중복 설계하지 않는다.
- 구조 카드의 `이 작법이 실제로 바꾸는 전개` 한 문장과 기능표의 대응 E로 적용을 드러낸다. 예: 프라이탁은 절정 후 실제 결과, Story Circle은 획득으로 발생한 대가, 트루비는 약점이 부른 선택과 자기인식 뒤 달라진 행동이다. 작법 이름을 갈아 끼운 동일 줄거리로 네 안을 제출하지 않는다.
- 60초 인트로는 선택 구조의 첫 사건에 연결한다. 작법의 모든 단계를 인트로에 압축하거나 구조에 맞춘다는 이유로 훅을 늦추지 않는다. 감정·인과·반전 표는 기존 4-C에 통합하고 새 확인 관문이나 반복 설명은 추가하지 않는다.

## STR01 — 시드 필드 3막

설정 → 대립 → 해결의 큰 흐름을 쓴다. 1막 말의 전환은 주인공을 본격 갈등으로 밀어 넣고, 2막 말의 전환은 해결을 향한 행동 방향을 바꾼다. 두 전환은 새 장소로 이동하는 것만으로 성립하지 않는다.

- 주 구조: `1막 설정 / 제1 전환 / 2막 대립 / 제2 전환 / 3막 해결`을 사건 E에 연결한다. 전환은 해당 막의 경계 기능이며 별도의 두 막을 추가하는 것이 아니다.
- 보조일 때: 선택한 주 구조 안에서 도입의 약속과 해결의 응답, 큰 전환 두 곳만 확인한다.
- 야담 적용: 세 가지 빚이 차례로 재산·평판·가족 책임을 시험하게 하고, 주인공의 마지막 선택으로 아버지의 뜻을 새롭게 읽게 한다.
- 검사: 전환을 제거하면 이후 행동 방향이 실제로 달라지는가? 해결이 앞서 심은 능력·증거·선택에서 나오는가?
- 길이 비율은 설계 참고다. 메인 프롬프트의 고정 5막 20챕터 할당량에 맞춰 사건을 배치하며 Save the Cat의 위치 수치를 가져오지 않는다.

## STR02 — Story Grid 5계명

일상을 흔드는 사건 → 시도가 어려움을 키우며 전환점에 도달 → 양립할 수 없는 선택 → 선택의 실행 → 결과의 다섯 기능을 쓴다. 위기는 단순한 위험이 아니라 **각각 대가가 있는 선택지 사이의 결정**이다. 절정은 그 결정을 행동으로 실행하는 순간이다.

- 주 구조: 위 다섯 기능으로 전체 사건을 연결한다. 점증하는 난관은 여러 사건으로 나눌 수 있다.
- 보조일 때: 전체 이야기 또는 사전에 지정한 핵심 선택 장면들에만 다섯 기능을 연결한다. 모든 문단에 다섯 사건을 억지로 추가하지 않는다.
- 기록: 무엇이 균형을 깨는가 / 왜 기존 방법이 막히는가 / 선택 A와 그 대가 / 선택 B와 그 대가 / 실제 선택 행동 / 그 때문에 달라진 결과.
- 검사: 선택지가 사실상 같은가? 선택 없이 조력자가 해결하는가? 어느 쪽을 골라도 결과가 같다면 다시 설계한다.

## STR03 — 프라이탁 피라미드

도입 → 상승 → 절정 → 하강 → 종결의 흐름으로 긴장을 설계한다. 절정 뒤에는 그 사건이 낳은 결과가 이어진다. 하강은 모든 긴장이 사라진다는 뜻이 아니다.

- 주 구조: 다섯 기능의 사건 범위를 정하고, 절정 이전 축적과 이후 결과를 구분한다. 절정을 무조건 마지막 챕터로 옮기지 않는다.
- 보조일 때: 선택한 한 갈등의 긴장 곡선만 점검한다.
- 야담 적용: 장터의 어리숙한 인물을 향한 오해가 공개 시험에서 뒤집히고, 그 시험의 결과로 탐욕스러운 인물의 권한과 관계가 달라진다.
- 검사: 정점의 전환이 앞선 축적에서 발생하는가? 정점 뒤 장면들이 결과를 보여 주는가? 같은 강도의 가짜 정점을 계속 반복하지 않는가?
- 비극의 파국을 모든 야담에 강제하지 않는다. 권선징악·화해의 종결은 이 생성기의 장르 적용이다.

## STR04 — 기승전결

기: 상황과 의미를 연다. 승: 앞 내용을 발전시킨다. 전: 관점·관계·사건의 의미를 바꾼다. 결: 전환을 앞 내용과 연결하여 마무리한다.

- 주 구조: 네 기능을 각각 사건 E에 연결한다. 롱폼에서는 승과 전 안에 여러 시도·질문 회수 장면을 넣는다.
- 보조일 때: 핵심 반전 하나의 `준비 → 누적 → 새 해석 → 앞 내용과 연결`을 점검한다.
- 검사: 전이 뜬금없는 새 인물·새 물건인가? 결을 읽으면 기의 의미가 달라지는가? 전을 반드시 범인 폭로로 만들지 않는다.

## STR05 — 댄 하먼 Story Circle

익숙한 상태 → 필요·욕망 → 낯선 상황 진입 → 적응과 탐색 → 원하는 것 획득 → 대가 지불 → 돌아옴 → 변화의 여덟 기능을 쓴다.

- 주 구조: 여덟 기능을 모두 연결한다. 귀환은 지리적 귀향 또는 관계·일상으로의 복귀로 구현할 수 있다.
- 보조일 때: 사건을 주 구조 순서대로 유지하며, 처음 원한 것·얻은 것의 대가·마지막 행동의 차이를 추적한다.
- 야담 적용: 객주를 떠난 자식이 독립을 얻지만 타인의 돌봄을 외면한 대가를 겪고, 돌아와 이전과 다른 책임을 선택한다.
- 검사: 획득과 대가가 연결되는가? 마지막 변화가 교훈 설명이 아니라 처음과 다른 행동으로 보이는가?

## STR06 — Story Spine

초기 상태 / 반복되던 일상 / 일상을 깨는 사건 / 그 결과 1 / 그 결과 2 / 그 결과 3 / 결정적인 결과 / 이후의 새 일상이라는 여덟 문장 틀로 인과를 정리한다. 중간 결과는 작품에 맞게 늘리거나 줄일 수 있다.

- 주 구조: 각 문장의 인과를 사건 E에 펼쳐 쓴다. 여덟 줄 요약을 완성 대본으로 제출하지 않는다.
- 보조일 때: 확정한 사건표의 인접 사건 사이를 `앞 사건 때문에 다음 행동을 한다`로 연결해 검사한다.
- 검사: 단지 시간이 지나서 다음 사건이 생기는가? 이전 선택을 지워도 다음 사건이 그대로라면 연결 원인을 보강한다. 설명 문장으로만 인과를 주장하지 말고 실제 행동을 바꾼다.
- 창안자는 Kenn Adams다. Pixar가 만든 작법이라고 표기하지 않는다.

## STR07 — 트루비 22단계

인물의 욕망·약점·도덕적 선택과 상대의 행동이 줄거리를 만들어 내도록 설계한다. 아래는 핵심 기능을 한국어로 간추린 설계 항목이며 책의 문장을 인용한 것이 아니다. 22개 항목을 22개 챕터로 만들지 않는다. 첫 항목은 결말을 먼저 정하는 **설계 작업**이며, 결말 장면을 도입에 노출하라는 지시가 아니다.

| 항목 | 확인할 기능 |
|---|---|
| TR01 | 마지막 자기인식·필요·욕망을 역으로 설계 |
| TR02 | 과거의 상처와 이야기 세계 |
| TR03 | 약점과 변화의 필요 |
| TR04 | 사건을 일으키는 계기 |
| TR05 | 구체적으로 추구하는 욕망 |
| TR06 | 협력자 |
| TR07 | 상대와 풀어야 할 의문 |
| TR08 | 협력자인 듯 행동하는 적 |
| TR09 | 첫 발견과 결정, 달라진 욕망·동기 |
| TR10 | 목표를 이루려는 계획 |
| TR11 | 상대의 계획과 주요 반격 |
| TR12 | 목표를 향한 연속 행동 |
| TR13 | 협력자의 비판·반발 |
| TR14 | 패배한 듯 보이는 상황 |
| TR15 | 두 번째 발견과 결정, 집요해진 행동 |
| TR16 | 관객에게 새로 드러나는 사실 |
| TR17 | 세 번째 발견과 결정 |
| TR18 | 최종 대결로 향하는 문턱과 극한 시험 |
| TR19 | 결정적 대결 |
| TR20 | 자기인식 |
| TR21 | 도덕적 선택 |
| TR22 | 달라진 균형 |

- 주 구조: TR01~TR22 각각을 `설계 / 사건에 적용 / 통합 / 해당 없음`으로 표시한다. 적용·통합 항목에는 대응 E를, 설계 항목에는 인물·결말 사실을 기록한다. `해당 없음`에는 소재상 이유를 적는다. 도입에서 이미 알고 있는 사실을 관객에게 속이는 장치로 이용하지 않는다.
- 약점·필요, 욕망, 상대, 계획, 대결, 자기인식, 새로운 균형의 핵심 축은 누락하지 않는다. 거짓 동맹·관객 선공개 같은 부가 장치는 적합할 때 쓰며 인물 수를 채우기 위해 추가하지 않는다.
- 보조일 때: 약점과 욕망이 낳는 잘못된 선택, 상대의 반격, 마지막 도덕적 선택을 추적한다. 22개 전체 순서를 보조 구조로 강요하지 않는다.
- 검사: 인물의 약점을 다른 것으로 바꾸면 줄거리도 달라지는가? 악역에게 독립적인 목표·계획이 있는가? 깨달음 직후 선택 행동이 달라지는가?

## STR08 — Save the Cat 감정 비트

주 구조로 선택할 때는 아래 15비트를 사용한다. 위치 범위와 피날레 세부 단계는 **기존 생성기의 운용 기준을 유지한 것**이며, 다른 작법의 보편적 필수 위치가 아니다. 순서를 유지하되 설정·관계처럼 서로 겹쳐 진행되는 기능은 한 사건에 함께 배치할 수 있다.

| # | 비트·합본 위치 | 반드시 일어날 사건 변화 | 궁금증 작동 방식 |
|---:|---|---|---|
| 1 | **오프닝 이미지** 0~1% | 주인공의 결핍·불균형을 한 장면으로 보여준다. | 설명되지 않는 구체적 모순 Q0를 한 개만 보여준다. |
| 2 | **주제 제시** 3~5% | 조연이 이 작품에만 맞는 주제 대사를 말하고, 주인공은 흘려듣거나 반박한다. | `주인공이 언제 이 말의 뜻을 깨달을까`라는 감정 질문을 만든다. |

| 14 | **피날레** 80~99% | ①세력 정비 ②계획 실행 ③최종 역습 ④내적 결단 ⑤새 방식의 승리 순으로 진행한다. 주인공의 선택이 결말을 만든다. | Q1·Q4와 최종 반전을 공정 단서로 회수한다. 폭로 뒤 관계·행동·대가까지 보여준다. |
| 15 | **파이널 이미지** 99~100% | 오프닝과 닮았지만 주인공의 변화가 눈에 보이는 반대 이미지로 끝낸다. | 핵심 질문을 모두 닫고, 속편 미끼 대신 여운을 남기는 한 문장으로 마친다. |

- 주 구조 검사: 15개 기능, 중반 전환, 실제 손실, 앞선 단서와 관계에서 나온 새 계획, 결단과 보상, 처음과 달라진 마지막 모습을 확인한다. 위 위치 범위는 STR08을 주 구조로 선택했을 때만 검사한다.
- 보조일 때: 주 구조에 필요한 감정 기능 3~5개를 골라 `기대 / 작은 성취 / 상실 또는 대가 / 깨달음과 재결단 / 보상` 등의 변화로 사건 E에 연결한다. 전체 15비트·고정 백분율·피날레 5단계를 추가로 강제하지 않는다.
- 감정은 `슬펐다`, `감동했다` 같은 설명보다 인물의 행동·관계·소품의 뜻이 달라지는 장면으로 만든다.

## STR09 — 축소형 영웅의 여정

큰 흐름은 출발·시련과 변화·귀환이다. 아래 여섯 기능은 이 생성기의 **야담용 축약**이며 Campbell의 단일 공식 6단계나 Vogler의 12단계라고 부르지 않는다.

- 주 구조의 여섯 기능: 익숙한 삶과 부름 / 경계 넘기 / 시험과 배움 / 결정적 시련 / 얻은 것을 가지고 돌아옴 / 달라진 삶과 나눔.
- 보조일 때: 핵심 시험이 마지막 선택에 어떤 능력·깨달음을 주었는지와 귀환 후 변화만 확인한다.
- 야담 적용: 집을 떠난 도령이 장사를 배우고, 이익보다 약속을 지키는 시련을 거친 뒤 고향에서 달라진 거래 방식을 실천한다.
- 검사: 조력자 선물 하나가 전부 해결하는가? 시련에서 배운 것이 최종 행동에 쓰이는가? 귀환이 단순한 출세 보고인가?

## STR10 — 아리스토텔레스의 완결성과 인과

처음·중간·끝을 갖춘 하나의 행동을 이루고, 사건들이 개연성 또는 필연성으로 이어지도록 한다. 반전과 인식은 사용할 수 있는 장치이며 모든 작품에 동일 개수로 강제하는 공식이 아니다.

- 주 구조: 시작에서 원인을 세우고, 중간에서 그 결과가 다음 선택을 낳으며, 끝에서 중심 행동의 결과를 완결한다. 세 기능에 여러 사건 E를 연결한다.
- 보조일 때: 시작의 약속과 결말의 응답, 앞 선택과 뒤 결과의 연결을 검사한다.
- 검사: 핵심 사건을 제거하거나 순서를 바꿔도 아무 영향이 없는가? 결말을 설명하기 위해 새 혈연·초능력·유언장을 처음 꺼내야 하는가? 그런 경우 앞선 원인과 증거를 보강한다.
- 시드 필드의 3막 전환점이나 Save the Cat의 백분율과 같은 것으로 취급하지 않는다.

## 적용 흔적과 최종 검사

구조 이름만 기록하면 적용한 것으로 인정하지 않는다. 01번 파일의 구조 카드·사건표·주 구조 기능표·보조 적용표를 함께 채운다. 최종 검사에는 `검사 항목 / 사건 E / 실제 챕터와 근거 문장 / 판정`을 남긴다. 해당 작법을 선택하지 않았으면 그 작법 전용 검사는 `NOT_APPLICABLE`이다.

공통으로 확인할 것은 사건 사이의 원인, 주인공의 선택과 결과, 사전 단서와 회수, 제목 약속의 실현이다. 기계적인 파일·번호 검사는 의미가 실제로 구현됐음을 보증하지 않는다. 본문을 읽고 근거가 있는 경우에만 의미 검사를 PASS로 기록한다.
