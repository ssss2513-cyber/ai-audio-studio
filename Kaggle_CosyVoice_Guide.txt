CosyVoice 2·3 — 공유 사이트에서 캐글 음성 만들기 / v2.9.60

공유 사이트: https://voice-studio.streamlit.app/

이제 공유 사이트에서 생성 버튼을 누르고, 완성된 음성도 공유 사이트에서 받습니다.
단일 모델은 캐글 작업 1개/GPU 2개, 혼합 대본은 모델별 작업 2개가 동시에 계산합니다.
혼합은 작업마다 T4 GPU 2개를 요청하며 실제 시작은 계정 한도와 자원 배정에 따릅니다.
GPU당 3개 생성 + 다음 대사 3개 사전 준비를 사용합니다.
GPU 2개인 작업 하나에서 최대 6개가 생성되고 다음 6개를 준비합니다.
실행 중 하나가 끝나면 다른 두 대사의 완료를 기다리지 않고 다음 대사를 시작합니다.
대사·화자·스타일·참고 파일을 먼저 받아 두고, 완료 음성은 별도 작업으로 저장합니다.
공유 음향·파형 계산은 충돌을 막기 위해 차례로 처리합니다.
메모리 부족 시 완료 음성을 보관하고 새 대사를 중단하며 음질 설정을 낮추지 않습니다.
업데이트는 새 캐글 작업부터 적용됩니다. 이미 실행 중인 작업은 기존 방식으로 끝까지 진행됩니다.
기존 코랩도 계속 사용할 수 있습니다.
앞서 드린 그림 안내서는 ‘캐글에서 직접 실행하는 수동 방식’입니다.
새 자동 연결에는 노트북 가져오기, 대본 ZIP 업로드, 캐글 Run All이 필요 없습니다.

1. 처음 한 번, 내 캐글 연결

   적용 버전 v2.9.60을 확인하세요. 현재 완성 음성이 열려 있다면 먼저 저장하세요.
   왼쪽 ‘🚀 코지2·3 · 캐글 연결’을 엽니다.

   이미 발급받은 토큰을 사이트의 ‘캐글 API 토큰’ 칸에 붙여넣습니다.
   토큰이 없는 경우에만 https://www.kaggle.com/settings/api 에서 발급받습니다.
   ‘내 캐글 연결’을 누르고 ‘캐글 계정 인증 완료 · 내아이디’를 확인합니다.
   연결 성공 시 생성 위치도 자동으로 ‘캐글 GPU 2개’로 선택됩니다.
   이미 연결된 접속에서 ‘현재 생성 위치는 기존 코랩’이 보이면
   ‘캐글로 음성 생성하기’를 누르세요. 기존 토큰을 다시 발급받을 필요가 없습니다.
   계정 인증과 GPU·모델 준비는 별개입니다. 모델 준비는 생성 버튼을 눌러야 시작합니다.

   kaggle.json이 있다면 ‘kaggle.json 파일 등록’을 선택해 올려도 됩니다.
   이 파일은 캐글 API 설정의 Legacy API Credentials → Create Legacy API Key에서 받습니다.
   접속한 사람마다 자기 캐글 계정을 연결합니다.
   인증정보는 현재 접속에만 보관하며, 대본·노트북·음성 결과에 넣지 않습니다.

2. 공유 사이트에서 대본과 목소리 설정

   대본을 분석한 뒤 본문 2번 ‘캐글 모델 설정’으로 갑니다.
   ‘캐글에서 사용할 음성 모델’을 고르고 ‘전체 N명에 CosyVoice 2/3 적용’을 누릅니다.
   코지3 기본 목소리는 화자 카드에서 성별 → 목소리 → 스타일 순서로 고릅니다.
   코지3 기본 20종은 참고 녹음을 올리지 않아도 됩니다. ‘내 한국어 녹음’도 선택할 수 있습니다.
   코지2는 화자마다 참고 음성을 올리고 그 녹음에서 실제로 말한 대사를 입력합니다.
   두 모델을 섞으려면 화자 카드의 엔진을 각각 코지2 또는 코지3로 선택합니다.
   모델 설치는 캐글에서 자동으로 진행하며 별도 서버 주소는 입력하지 않습니다.
   API 연결이나 GPU·기본 엔진 선택만으로 기존 화자 설정을 덮어쓰지 않습니다.
   전체 적용 버튼을 눌렀을 때만 화자 모델을 바꾸며, 코지2 적용 시 등록된 참고 음성을 유지합니다.
   Qwen 등 다른 엔진이 남아 있으면 해당 화자를 표시하고 캐글 생성은 시작하지 않습니다.
   본문 3번에 참고 음성·대사 미등록 안내가 보이면 해당 화자 카드에서 입력합니다.

대사별 감정 설정

   화자 카드 아래 ‘대사별 감정 넣기’ 표에서 감정과 강도를 고릅니다.
   ‘감정 설정 저장’을 누르면 대본에도 감정 표시가 저장됩니다.
   예: 만복: [분노, 강하게] 어찌 이런 일이 있을 수 있단 말이오!
   같은 화자라도 다음 줄에는 [울먹임], [속삭임] 등 다른 감정을 지정할 수 있습니다.
   한 줄에는 한 감정만 적용합니다. 중간에 바뀌면 같은 화자로 줄을 나누세요.
   ‘선택 대사 감정 미리듣기’는 저장한 감정으로 선택 대사를 생성합니다.
   캐글 미리듣기도 GPU 설치·모델 준비가 필요하고, 결과는 캐글 진행 화면에 나옵니다.
   감정 표시는 자막·낭독 본문에서 제외합니다. 목소리·성별 선택은 유지합니다.
   감정이 해당 대사의 화자 스타일보다 우선하며, ‘화자 스타일 사용’은 기존 동작입니다.
   감정과 강도를 바꾼 대사는 이전 감정의 완료 음성을 재사용하지 않습니다.
   코지2·3 / Gemini 지원. 감정 표현은 모델과 참고 음성에 따라 달라집니다.

3. 공유 사이트에서 생성

   ‘3. TTS 오디오 및 자막 생성’으로 내려갑니다.
   전체 또는 원하는 대사 구간을 고릅니다.
   ‘이 사이트에서 음성 생성 · 캐글 GPU 2개’를 누릅니다.
   코지2·3를 섞어 선택하면 버튼이 ‘코지2·3 동시 생성’으로 바뀝니다.

   사이트가 내 캐글 계정에 대본·참고 음성을 비공개로 보내고 생성 작업을 시작합니다.
   화면에서 전송 → GPU 대기 → 설치·모델 준비 → 생성 → 결과 수신을 확인합니다.
   한 GPU가 먼저 끝나면 다음 대사를 바로 맡습니다.
   코지2·3 혼합은 캐글 작업을 각각 하나씩 동시에 제출합니다.
   모델별 설치·준비·생성이 독립적으로 진행됩니다. 준비된 모델부터 대사를 생성합니다.
   각 모델의 GPU는 한 대사가 끝나면 다음 대사를 즉시 맡습니다.
   둘 다 완료되면 원본 WAV를 대본 순번대로 합친 뒤 MP3로 한 번만 인코딩합니다.
   연결부에서 파형이 갑자기 끊기는 경우 시작·끝 최대 2ms를 완만하게 처리합니다.
   대사를 자르거나 겹치지 않으며, 대사 간격·순서·길이를 유지합니다.
   음성 전체에 잡음 제거·음량 보정 필터를 적용하지 않습니다.
   생성된 대사 내부의 기계음이나 끊긴 발음 자체를 복구하는 기능은 아닙니다.
   한 모델이 실패해도 다른 모델은 계속 생성하고 완료분을 보관합니다.
   동일한 대본과 설정으로 생성 버튼을 다시 누르면 완료 모델은 재사용합니다.
   ‘완료 파일도 새로 만들기’를 켜면 두 모델 모두 새로 생성합니다.
   다른 GPU 작업이 실행 중이면 캐글 동시 실행 한도에 걸릴 수 있습니다.
   원래 모델, 화자, 스타일, 속도, FP32 정밀도와 추론 설정을 유지합니다.

   새 캐글 작업마다 GPU 배정, 환경 설치, 모델 준비 시간이 필요합니다.
   미리듣기 버튼도 이 방식으로 생성하므로 한 대사라도 준비 시간이 필요합니다.
   캐글의 진행 기록이 늦게 반영되면 사이트의 완료 개수도 늦게 바뀔 수 있습니다.
   실제 완료 시간이나 특정 속도를 보장하지 않습니다.

4. 공유 사이트에서 결과 받기

   ‘캐글 생성 진행·완성 음성’에 완료 안내가 나타납니다.
   ‘완성 음성 들어보기’로 듣습니다.
   ‘전체 대사 MP3 한 파일 받기’로 대본 순서대로 합친 MP3를 받습니다.
   SRT/VTT 자막과 MP3+자막 ZIP도 사이트에서 받을 수 있습니다.
   큰 ZIP은 ‘준비’를 누른 다음 나타나는 저장 버튼으로 받습니다.

   투명 자막 영상도 필요하면 결과 아래 ‘투명 자막 MOV 만들기·다운로드’를 엽니다.
   가로 16:9 또는 세로 9:16과 글자 크기를 고른 뒤 ‘투명 자막 MOV 만들기’를 누릅니다.
   완료되면 ‘투명 자막 MOV 받기’로 subtitles.mov를 저장합니다.
   큰 파일은 다운로드 준비를 누른 다음 나타나는 저장 버튼을 누르세요.
   기본은 가로 1920×1080, 30fps, 하단 중앙 흰 글씨와 검은 테두리입니다.
   배경은 투명하고 소리는 없습니다. 원본 SRT의 자막 시간을 사용합니다.
   편집 사이트의 ‘자막영상 MOV’에 subtitles.mov를 넣고,
   ‘나레이션’에는 full_audio.mp3를 넣어 둘 다 0초부터 배치하세요.
   MOV 변환은 공유 사이트에서 별도로 진행하며 음성·캐글 작업을 다시 생성하지 않습니다.
   기존 완성 결과를 불러온 뒤에도 MOV만 만들 수 있습니다.
   MOV는 별도 다운로드이며 기존 MP3+자막 ZIP에는 넣지 않습니다.

5. 끊기거나 중단된 경우

   미리듣기 버튼을 누르면 그 화자 카드의 버튼 바로 아래에
   요청 시각·작업 번호·현재 단계가 나타납니다. 생성이 끝나면 같은 자리에서
   ▶ 재생 버튼으로 듣고 MP3를 받을 수 있습니다. 오류도 같은 자리에 남습니다.
   ‘사이트 접수’와 ‘캐글 등록 확인’은 다릅니다. GPU 작업이 거절되면 오류를 표시합니다.
   대본 입력 위의 ‘캐글 작업 목록’은 펼쳐져 있으며 현재 접속의 요청을 표로 보여줍니다.
   ‘작업 목록 화면 갱신’은 저장된 상태를 다시 표시합니다.
   ‘내 캐글 작업 목록 불러오기·새로고침’은 같은 계정의 이전 캐글 작업을 조회합니다.
   두 버튼 모두 음성을 새로 생성하지 않습니다.
   버전 표시 아래 ‘화면·업데이트 새로 표시’를 누르면 현재 접속을 유지하며 갱신합니다.
   공유 사이트의 메뉴에는 Rerun 항목이 없을 수 있으므로 본문의 이 버튼을 사용하세요.
   브라우저 F5로 새 접속이 열리면 현재 대본·설정이 초기화될 수 있습니다.

   v2.9.59에서 대본 데이터와 실행 작업의 이름 충돌을 수정했습니다.
   최초 생성 요청 오류가 'already in use by a dataset'였던 작업은
   같은 계정으로 연결된 화면에서 생성 제한을 해제합니다.
   미리듣기 또는 생성 버튼을 다시 누르면 분리된 새 이름으로 요청합니다.
   토큰을 다시 발급받거나 기존 대본·참고 음성을 지울 필요가 없습니다.
   다른 409·403 오류는 이 이름 충돌과 구분해서 기존 상태 확인 절차를 사용합니다.

   ‘이전 작업의 상태 확인이 필요합니다’ 때문에 미리듣기가 막히면,
   그 화자 카드 바로 아래 ‘이전 작업 상태 확인·결과 받기’를 누르세요.
   대본 입력 위의 ‘캐글 작업 이력 · 진행·오류·결과 확인’에도 같은 버튼이 있습니다.
   생성 요청 전에 중단된 작업은 제한을 해제하며, 미리듣기 버튼을 다시 누를 수 있습니다.
   이미 제출됐을 가능성이 있으면 실제 작업 상태를 읽고 결과를 가져옵니다.

   빨간 오류창 바로 아래 ‘오류 기록 TXT 받기’를 눌러 기록을 받을 수 있습니다.
   최초 생성 요청 오류도 접힌 메뉴 밖에 표시합니다. 문의할 때 TXT를 첨부하세요.
   ‘단계별 이력·오류·실행 로그’에는 상세 단계와 최근 캐글 실행 로그가 있습니다.
   ‘등록 미확인’ 주소는 사이트가 미리 만든 예정 주소이며 GPU 실행 성공 표시가 아닙니다.
   계정 인증 통과와 캐글 작업 등록·GPU 실행 성공은 별도로 확인합니다.
   같은 접속에서 진행한 이전 작업은 ‘이 접속에서 보관한 이전 작업’에서 선택합니다.
   단계 이력은 작업마다 최근 160개를 보관하며 업데이트 이전 단계는 복원하지 않습니다.

   사이트를 새로 열어 이전 기록이 안 보이면 같은 캐글 계정을 연결하고,
   ‘내 캐글 작업 목록 불러오기·새로고침’ → 작업 선택 → ‘선택 작업 상태·결과 불러오기’.
   목록에는 캐글에 등록된 본인 Voice Studio 작업만 표시됩니다.
   ‘이전 목록 더 보기’로 앞선 작업을 찾을 수 있습니다.
   목록 조회와 복구 버튼은 GPU 음성을 새로 생성하지 않습니다.

   제출이 끝난 작업은 사이트 창을 닫아도 캐글에서 계속 실행됩니다.
   캐글 사용 한도·런타임 제한까지 해제되는 것은 아닙니다.
   사이트의 ‘내 캐글 작업 열기’ 주소를 보관해두세요.

   사이트에 새로 접속했다면 같은 캐글 계정을 연결하고,
   왼쪽 ‘이전 캐글 작업 불러오기’에 그 작업 주소를 넣습니다.
   작업을 다시 생성하지 않고 현재 상태나 저장된 결과를 가져옵니다.

   ‘상태·결과 다시 확인’도 같은 작업의 상태와 다운로드만 확인합니다.
   동시 작업은 진행 화면의 ‘두 모델 작업 복구 파일 보관’을 눌러 JSON을 보관하세요.
   다시 접속했다면 같은 계정 연결 → ‘이전 캐글 작업 불러오기’ → 복구 JSON 선택
   → ‘두 모델 작업 함께 불러오기’를 누릅니다. 두 작업의 결과를 받아 전체 순서로 합칩니다.
   복구 파일에는 대본·화자 설정과 두 작업 주소가 있고 API 키는 없습니다.
   동시 작업 전체를 멈추려면 코지2·코지3 작업 링크에서 각각 중지하세요.
   업로드·생성 요청의 응답이 끊겼다고 같은 작업을 자동 중복 제출하지 않습니다.

   401·403 오류만으로 토큰 만료라고 판단하거나 토큰을 계속 재발급받지 마세요.
   ‘현재 토큰으로 연결 다시 확인’은 입력된 토큰을 그대로 사용합니다.
   작업 조회가 거부되면 계정 인증과 작업 등록 여부를 구분해서 확인합니다.
   계정 인증이 정상이고 작업 자체가 없다는 404 응답까지 확인되면
   이전 작업 때문에 막혀 있던 생성 제한을 해제합니다.
   작업 접근 여부가 불명확하면 기존 작업을 보존합니다.
   수동 통합 노트북은 기존처럼 한 캐글 작업에서 코지2 다음 코지3를 처리합니다.
   모델별 별도 동시 작업은 공유 사이트의 ‘코지2·3 동시 생성’ 버튼으로 사용하세요.
   ‘캐글 오류 상세 보기’에서 현재 오류와 최초 생성 요청 오류를 각각 볼 수 있습니다.

   409 충돌이 나면 실제 작업이 시작됐는지 자동으로 확인합니다.
   실행 중이면 진행 상황을 이어받고, 결과 저장이 늦으면 다운로드만 다시 시도합니다.
   작업 자체가 등록되지 않은 것을 확인하면 새 생성을 막던 상태를 해제합니다.
   그때 위의 생성 또는 미리듣기 버튼을 다시 누르세요.
   계속 오류가 나면 ‘캐글 오류 상세 보기’에서 발생 단계와 캐글 응답을 확인합니다.
   409라는 숫자만으로 API 키 오류나 GPU 한도 초과라고 단정하지 않습니다.
   기존 접속의 409 오류도 업데이트 뒤 계정이 연결되어 있으면 한 번 자동 확인합니다.

   일부 생성 후 오류가 나고 완료분이 저장됐다면 사이트가 resume.zip도 받아둡니다.
   같은 접속에서 대본·설정을 유지하고 다시 생성하면 이 완료분을 재사용합니다.
   대본이나 설정을 변경하면 새 작업으로 생성합니다.
   완료 파일도 새로 만들기를 켜면 기존 완료분을 사용하지 않습니다.

   실행을 중지하려면 작업 목록의 ‘⏹ 현재 작업 중지 화면 열기’를 누릅니다.
   열린 캐글 화면에서 해당 실행 중인 버전을 취소해야 실제 GPU가 멈춥니다.
   링크를 열거나 사이트를 닫는 것만으로는 중지되지 않습니다.
   코지2·3가 따로 실행 중이면 ‘코지2 중지 화면 열기’, ‘코지3 중지 화면 열기’를 각각 사용합니다.
   사이트는 실제 상태를 확인해 ‘캐글 중지 처리 중’에서 ‘중지 완료’로 바꿉니다.
   캐글이 결과를 저장하기 전에 강제로 종료되면 저장하지 못한 대사는 복구할 수 없습니다.

   코지2와 코지3의 작업 주소·진행 수·실행 로그는 각각 기록됩니다.
   혼합 대본은 두 작업을 동시에 요청하지만 실제 시작은 계정의 GPU 배정에 따릅니다.
   두 모델의 음성이 모두 완료되면 사이트에서 원래 대본 순서대로 합칩니다.

   v2.9.61부터 모델별 남은 대사 12개 이상은 TensorRT FP32 가속을 준비합니다.
   로그에 ‘가속 상태’와 ‘화자 준비/발음 계산/음향 대기/파형 계산’ 시간이 나옵니다.
   ‘tensorrt_fp32’이면 가속 적용, ‘pytorch_fp32’이면 기존 FP32 계산입니다.
   가속 준비 실패 이유도 표시합니다. 12개 미만의 미리듣기·짧은 작업은 최초 변환을 생략합니다.
   처음 가속 파일을 만드는 데 추가 시간이 걸립니다. 같은 실행 환경에서는 재사용합니다.
   새 캐글 배치 작업은 새 환경이라 필요한 모델과 가속 파일을 다시 준비합니다.
   사이트 사용자가 코지2·3 노트북이나 모델 파일을 매번 직접 받아 올릴 필요는 없습니다.
   업데이트는 새로 시작하는 작업부터 적용됩니다. 이미 진행 중인 작업은 기존 코드로 끝납니다.

6. 코랩 사용

   왼쪽 ‘음성을 계산할 GPU’를 ‘기존 코랩 연결’로 바꾸면 기존 방식입니다.
   기존 코랩 노트북, 접속 주소, 모델과 생성 방식은 유지했습니다.
   Gemini 등 다른 엔진과 섞인 전체 대본은 기존 연결 방식을 사용하세요.

계정의 휴대폰 인증과 GPU 사용 가능 시간은 캐글에서 확인해야 합니다.
이번 변경에서는 요청에 따라 테스트·컴파일·모델 실행·실제 음성 생성을 하지 않았습니다.
