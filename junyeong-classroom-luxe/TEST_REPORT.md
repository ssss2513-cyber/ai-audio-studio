# 점검 보고 · 1.0.0

## 수행한 점검

Python 3.13, FastAPI 0.128.2, Node.js 22 구문 검사 및 로컬 Chromium 렌더러에서 확인했습니다. 기존 운영 사이트·실제 회원·사용자의 강의 영상은 사용하지 않았습니다.

백엔드 로컬 점검: **11 passed, 1 skipped(선택형 대용량 검사)**.

비밀번호 7자 거부·8자 가입, 승인 전 직접 주소 차단, 승인 후 허용, 승인 취소·제한·해제 시 세션 폐기, 자동 승인 변경의 기존 제한 계정 비적용, CSRF·출처·역할 검사, 변경 revision 충돌, 영상 비공개·휴지통·복원·영구 삭제, Range/HEAD 요청, 조각 재시도·해시·완료 요청 중복, 저장 경로 미공개, 개인정보 삭제·처리 기록, 이어보기 저장·쿠키 속성을 확인했습니다.

선택형 대용량 점검: **1 passed**. 2 GiB(2,147,483,648바이트) 합성 데이터를 8 MiB × 256조각으로 실제 로컬 전송·저장했습니다. 32조각 이후 새 클라이언트에서 상태를 확인하고 나머지를 전송했으며 조립 파일 크기·전체 SHA-256 일치를 확인했습니다. 약 9.9초는 로컬 시험 수치이며 인터넷 업로드 속도가 아닙니다.

## 화면 점검

정적 HTML을 Chromium 렌더러에 직접 로드하여 가상 데이터로 확인했습니다. 실행 환경의 URL 탐색 제한 때문에 실제 호스팅 URL을 방문하는 브라우저 종단간 검증은 하지 못했습니다.

- 1440px 데스크톱: 홈, 관리자 회원 목록·상세 창.
- 390px 휴대폰 크기: 홈·가입·관리자 목록의 전체 페이지 가로 넘침 없음.
- 확인한 화면에서 JavaScript 런타임 오류 없음.
- 모션 끄기, 메뉴 이동, 회원 상세 창 확인.

## 확인하지 못한 범위

실제 2GB 강의의 코덱·음성·화질, Windows 실행 BAT의 실기기 동작, 휴대폰/인앱브라우저 재생, 인터넷 장애·다중 사용자 부하, 외부 운영 HTTPS·프록시·백업 복구는 별도 검증이 필요합니다. 합성 데이터 전송은 영상 디코딩 검증이 아닙니다. 운영 서비스 보안 감사도 아닙니다.

기존 사이트 기능을 수정·반영하거나 기존 사이트를 삭제한 것이 아니며, 새 공개 주소에 배포하지 않았습니다.
