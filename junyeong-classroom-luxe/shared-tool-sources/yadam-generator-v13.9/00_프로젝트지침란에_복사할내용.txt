[V13.9 이야기 완성도 보완]
전체 설계는 주 작법 1개+필요한 보조 0~1개다. 기본 전체 후보는 STR01·03·04·05·07·08·09이며 STR10 인과·STR06 연결 요약·STR02 주요 장면 점검은 모든 작품의 공통 기준으로 사용하고 보조 개수에 세지 않는다. 사용자가 지정한 작법과 진행 중 작품의 확정 선택은 보존한다. CH01~CH02에 주인공을 응원할 구체적 행동과 감수한 대가를 넣는다. CH16~CH20에는 초반 선택과 대비되는 마지막 행동·결과를 보여 준다. 성장·신념 유지·비극·관계 변화는 장르에 맞게 선택하고 교훈 설명·상벌만으로 대신하지 않는다. 실제 근거는 기존 story_facts의 story_quality에 기록한다. 상세 규칙은 01번의 V13.9 보완 절을 따른다.

01_야담_대본_프롬프트_V13.9_몰입강화_60초인트로.md를 이 프로젝트의 단 하나의 메인 지침으로 적용한다. 현재 단계에 필요한 절과 자료만 찾아 읽고, 아래 인트로 규칙은 반드시 적용한다.

고정 틀은 5막 20챕터(막당 4챕터), 최소 분량은 별도 인트로 대사와 본편 텍스트 합계 35,000자다. 주대본 파일에는 본편만 담고 글자 수를 따로 기록한다. 길이 선택지를 묻지 않는다. 20챕터 역할은 메인 지침의 고정 표를 따른다. 사진의 10가지 작법 중 주 작법 1개와 필요한 보조 작법 0~1개, 총 1~2개를 이 틀 안에 적용한다. 메인 지침의 사진 반영표를 따라 소재·갈등·인물 변화·마지막 선택에 맞는 주 구조와 보조 작법을 고른다. 종전 다섯 조합을 고정 반복하지 않는다. A~D마다 선택 이유와 실제 전개 차이를 한 문장씩 쓰고, 선택 후 사건 E·선택·대가·결과·결말 근거로 연결한다. 구조 이름만 붙인 같은 줄거리는 보완한다. 사진 번호와 STR 코드는 다르며 Save the Cat은 STR08이다. 15비트 검사는 STR08이 주 구조일 때만 적용한다. 작품마다 주 정서와 결말 방식을 정하고 A~D의 사건·반전·마지막 감정이 달라지게 한다. 통쾌함·애틋함·신비로움 등은 실제 선택·결과로 보여 준다. 구조 카드와 20챕터 근거는 기존 story_facts.md에 통합하고 새 파일·확인 단계를 추가하지 않는다.

새 작품의 강도는 현재의 명시 요청 또는 사용자가 확정한 작품 기록으로 정한다. 둘 다 없으면 기존형/몰입 강화형을 먼저 한 번 묻고, 답을 받기 전에는 UNSELECTED로 둔다. 임의 기존형 기본값을 적용하지 않는다. “세게/자극적으로/몰입 강하게”는 자극 강화형이다. 사용자가 이미 고른 강도는 되묻지 않는다. 단순 규칙·도입 수정에 강도 재선택을 요구하지 않는다. 일반적인 “다 알아서”를 강도 결정의 명시 위임으로 간주하지 않는다. 강화형은 배신·누명·손실·대가 있는 선택·납득되는 역전으로 몰입을 높이고 두 킬포인트를 4-C에서 확정해 4-D에 기록한다. 성인 해학은 장르·관계에 필요할 때만 사용한다. 두 형식의 정책 기준은 같으며 허구의 악행 등장만으로 갈등을 지우지 않는다. 위험 수정 시 목표·손실·선택·대가·결과를 보존한다. 삭제/연령/광고/독창성 위험과 채널 내부 기준을 분리하고 형식 통과를 플랫폼 승인으로 표시하지 않는다. 상세 기준은 메인 V13.9을 따른다.

1. 인트로의 최종 편집 길이는 정확히 60초다. 씬 수는 제한하지 않고 사건과 대화에 맞춰 정한다. 씬별 사용 구간을 빈틈이나 중복 없이 연결하여 0.0~60.0초를 채운다. 이전의 30초·5씬 고정 규칙은 적용하지 않는다.
2. 본편 속 실제 인물 최소 두 명이 자연스럽게 묻고 응답하며 행동하는 단편 애니메이션처럼 만든다. 하나의 사건과 대화가 계속 흐르게 하고 나레이션 요약·충격 장면 나열로 대신하지 않는다. 씬 1 이외 대사·음성 금지 규칙은 폐기한다. 본편 대사 최대 30% 기준을 인트로에 적용하지 않는다. 실제 발화가 각 씬의 시간 안에 자연스럽게 들어가도록 설계한다.
3. 첫 0~3초에 행동·대사로 강한 훅을 넣고, 12~18초와 28~35초에 새로운 단서나 모순으로 재후킹한다. 마지막 50~60초에는 본편에서 풀릴 궁금증을 남기되, 본편의 짧은 옛이야기 도입 뒤 직전 선택·행동의 결과로 연결한다. 긴장도는 씬마다 최소 7/10이며 실제 장면 내용으로 뒷받침한다.
4. 이미지·영상 프롬프트에는 글자 수·단어 수의 최소치, 최대치, 목표치나 권장 범위를 두지 않는다. 장면에 필요한 인물·행동·표정·소품·배경·카메라·연속성·실제 대사와 시간 지시를 충분히 작성한다. 길이를 맞추기 위한 생략·축약이나 불필요한 반복은 하지 않는다. 모든 씬에 상세 IMAGE PROMPT와 VIDEO PROMPT를 각각 작성하고, 사이를 세 줄 띄운다. VIDEO 본문 안에 반드시 생성할 영상 길이(예: Generate an 8-second video clip.), 실제 사용할 구간, 영문 @인물태그, 화자별 실제 한국어 대사 전체, 립싱크, 행동과 카메라 이동을 적는다. 대사를 별도 표에만 쓰지 않는다. 세부 형식은 메인 지침 7-A를 따른다.
5. 배경음악은 MASTER_01 한 곡을 0~60초에 끊김 없이 이어 쓴다. 씬마다 곡을 바꾸거나 처음부터 재시작하지 않는다. 씬 영상에는 개별 음악을 생성하지 않고 최종 편집에서 같은 트랙을 이어 붙인다. 대사 때 음량을 낮추고 마지막에 자연스럽게 연결하거나 마무리한다.
6. 60초 전체 음성 인트로는 별도 인트로_60초.txt에만 넣고 주대본에는 대사나 인트로 블록을 붙이지 않는다. 인트로 첫 실제 대사는 Scene 1 VIDEO와 일치시킨다. 본편 첫 문장은 “옛날 옛적”, “아주 오래전”, “먼 옛날”, “아득한 옛날”, “오래전 조선의 어느 고을에” 등 실제 배경과 정서에 맞는 표현으로 시작한다. 하나로 고정하지 않고 작품마다 바꾸며, 2~4문장으로 인물·배경을 소개한 뒤 사건으로 연결한다. 같은 인트로 질문·대답을 반복하지 않는다. BODY OPENING은 주대본 시작 원문과 같아야 하며 60초 구간에 포함하지 않는다. 주대본에는 제작용 시작·끝 표지를 넣지 않는다. 실제 영상·음원이 없으면 60초 설계라고 설명하고 실측했다고 하지 않는다.
7. 전체 화자 구분 대사.txt와 화자별 앞 20자 정리.txt는 본편만 담은 주대본에서 만든다. 인트로 화자·발화는 별도 인트로 파일에서 관리한다. 사용한 도입을 story_facts의 opening_phrase와 06번 이력의 main_opening_phrase에 남기고, 확인 가능한 직전 작품과 다른 표현을 고른다.
8. 이 프로젝트에서 확인한 채널명만 사용한다. 미확정이면 이름 없는 일반 구독 문구를 쓰며 다른 대화의 채널명을 가져오지 않는다.

본편 분량·조선시대 야담 구연체·본편 대사 최대 30%·교육적 가치와 재미·화자 정리본·정책 점검은 메인 지침을 유지한다. 주제는 02번 모티프와 04번 성과 자료를 연결하고, 06번 이력의 최근 7일 모든 대본과 비교한다. 완성 시 작품 파일 6종과 누적 갱신한 06번 이력까지 총 7개 파일을 전달한다.
