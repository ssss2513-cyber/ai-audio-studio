야담 검증기 V11.20 — Claude 프로젝트 전용

1. 압축파일을 풉니다.
2. Claude에서 검증용 프로젝트를 엽니다.
3. 01_클로드_프로젝트지침_복사해서넣기.txt를 열어 내용 전체를 프로젝트의 지침란에 붙여넣고 저장합니다.
4. 나머지 6개 파일을 같은 프로젝트 자료에 올립니다.
   SKILL.md
   script-validation-rules.md
   intro-validation-rules.md
   output-contract.md
   analyze_yadam.py
   audit-map-template.json
5. 그 프로젝트의 새 대화에 검사할 대본·대사 파일·화자별 정리본·통합 인트로를 첨부합니다. 제목·썸네일·실제 이미지·영상도 있으면 함께 첨부합니다.
6. 아래 문장을 입력합니다.
   첨부한 대본과 60초 인트로를 검증하고 문제 있는 부분만 별도 수정본으로 만들어줘. 원본은 보존해줘.

분석만 원할 때:
   첨부 파일은 수정하지 말고 검증 결과만 알려줘.

화자 표시만 원할 때:
   기본 대본은 건드리지 말고 대사 파일의 나레이션과 실제 화자 표시만 바로잡아줘.

Python 파일은 Claude가 자동 측정에 사용할 자료입니다. 사용자가 직접 실행할 필요는 없습니다. Claude에서 코드 실행을 사용할 수 없으면 실행했다고 하지 않고 측정 불가 항목을 알려주도록 되어 있습니다.

지침란에 넣는 파일은 01번 하나입니다. SKILL.md는 자세한 작업 기준이므로 자료에 올립니다. 이전 검증기의 지원 자료는 이 판의 6개 파일로 교체해 구형 규칙과 함께 읽히지 않게 합니다. 기존 완성 대본·원고 파일은 보존합니다.

인트로는 60초이며 씬 수는 정해져 있지 않습니다. 인물들이 여러 씬에서 대화할 수 있고, 각 영상 프롬프트 안에 생성할 초수가 나옵니다. 배경음악은 한 곡을 60초 전체에 사용하도록 검사합니다. 실제 영상·음원이 없으면 설계만 검사합니다.

이번 파일 개정 작업에서 테스트는 실행하지 않았습니다.

이번 변경: V13.7 생성기의 고정 5막 20챕터·작법 1~2개·결말 정서 다양성에 맞췄습니다. 합본 최소 목표는 35,000자입니다. 막당 4챕터와 각 챕터의 역할·실제 사건 근거·최소 할당량을 검사합니다. 기존형/자극 강화형도 유지합니다. 두 킬포인트와 복선·선택·결과를 확인하고 위험 표현을 고칠 때 갈등과 재미를 보존합니다. 삭제/연령/광고/독창성 위험과 채널 내부 표현 기준을 따로 보고합니다.

analyze_yadam.py와 audit-map-template.json도 수정했습니다. 코드는 5막 20챕터·할당량·역할 원문 근거, 모드와 킬포인트 근거 위치를 확인하고 재미·인과·정책 판단은 Claude가 원문을 읽어 마무리합니다. 지침만 교체하지 말고 위 6개 자료를 모두 교체하세요.
