# 메종 루미엘 · Cloudflare R2 무료 영상 저장소 연결 안내

> **2026-10-18 확인.** 이 기능은 Google Drive의 `403 downloadQuotaExceeded`로 영상을 재생하지 못할 때 사용하는 **선택형** 저장소입니다. 기존 Google Drive 영상, 회원, 재생목록, 시청 기록은 자동 삭제하거나 옮기지 않습니다.

## 어떤 비용이 드나요?

Cloudflare R2 **Standard**의 현재 공식 월 무료 제공량은 **저장 10GB-month, Class A 100만 회, Class B 1천만 회, 인터넷 데이터 전송(egress) 무료**입니다.

- 공식 요금표: https://developers.cloudflare.com/r2/pricing/
- 시작 방법: https://developers.cloudflare.com/r2/get-started/
- R2 계정 개설 시 결제 설정을 요구할 수 있습니다. 무료 제공량 초과 및 다른 Cloudflare 서비스 사용에는 요금이 발생할 수 있습니다.
- **Railway 웹사이트 서버 비용은 R2의 무료 제공량에 포함되지 않습니다.** 기존 Railway 사용료는 별개입니다.
- 앱은 안전 여유를 두기 위해 등록 영상 합계를 **9,000,000,000바이트 미만**으로 제한하도록 만들었습니다. 이는 Cloudflare 계정 전체 사용량을 검사한 값이 아니므로 초과 요금을 절대 보장하지 않습니다.
- 2GB 영상 4개 정도는 무료 구간 안에 들어갈 수 있지만 5개는 파일의 실제 바이트 크기에 따라 초과될 수 있습니다.

## 처음 딱 한 번 · 연결 설정

1. **https://dash.cloudflare.com/** 에서 Cloudflare 계정 로그인/회원가입.
2. **Storage & databases → R2 → Overview → Create bucket** 선택.
3. 새 버킷은 **Standard**로 만들고 **Public Access는 끄세요**. 예를 들어 `maison-lumiel-lessons`로 정합니다. R2에서 요구하는 가입·결제 정보 등록은 운영자가 직접 처리해야 합니다.
4. R2 화면에서 **계정 ID(Account ID)** 와 **버킷 이름(Bucket)** 을 확인합니다.
5. **R2 API Tokens 관리**에서 해당 버킷에 읽기·쓰기 권한을 가진 S3 API 키를 발급받습니다. 필요 이상의 전체 계정 권한은 주지 않습니다.
6. **https://railway.com/** 에서 메종 루미엘 프로젝트 → **maison-lumiel 서비스 → Variables**로 이동하여 아래 네 변수를 비공개로 등록합니다.

| 변수 이름 | 넣을 값 |
| --- | --- |
| `R2_ACCOUNT_ID` | Cloudflare R2 계정 ID |
| `R2_BUCKET` | 앞에서 만든 비공개 버킷 이름 |
| `R2_ACCESS_KEY_ID` | Cloudflare R2 S3 API Access Key ID |
| `R2_SECRET_ACCESS_KEY` | Cloudflare R2 S3 API Secret Access Key |

**API 비밀키는 채팅, GitHub 파일, 노션, 스크린샷에 입력하거나 공유하지 마세요.** Railway의 Variables 전용 입력란을 사용하세요.

7. Railway 변경사항을 적용해 앱이 다시 실행되도록 합니다. 기존 SQLite 데이터·회원·영상 정보는 그대로 유지됩니다.

## 브라우저 직접 업로드를 위한 R2 CORS 설정

Cloudflare R2 버킷 → **Settings → CORS Policy**에 다음 설정을 추가합니다. 주소는 사용하는 실제 사이트의 주소와 정확히 일치해야 합니다.

```json
[
  {
    "AllowedOrigins": ["https://maison-lumiel-production.up.railway.app"],
    "AllowedMethods": ["PUT", "GET", "HEAD"],
    "AllowedHeaders": ["*"],
    "ExposeHeaders": ["ETag"],
    "MaxAgeSeconds": 3600
  }
]
```

R2 CORS 공식 문서: https://developers.cloudflare.com/r2/buckets/cors/

## 1강을 교체하려면

1. 메종 루미엘 관리자 로그인 → **영상 관리**.
2. 연결 성공 후 나타나는 **R2로 영상 업로드**에서 기존 원본 파일을 선택합니다.
3. 이미 등록된 1강을 그대로 유지하려면 1강 카드에 나타나는 **이 강의를 R2로 교체**를 누릅니다.
4. 원본 파일을 선택하고 제공 권한 체크 → 업로드를 시작합니다.
5. 영상은 16MiB씩 Cloudflare R2로 직접 전송합니다. 2GB라면 대략 128개 조각입니다.
6. 중간에 끊기면 같은 파일을 다시 선택해 이어올립니다. 끝날 때 서버에서 모든 조각과 파일 크기를 검사합니다.
7. 완료 후에도 기존 1강 **제목·영상 순서·회원 승인·시청 진행 기록은 보존**합니다. 기존 Google Drive 파일 자체는 삭제하지 않습니다.

**Google Drive 다운로드가 이미 한도 초과 상태이면 사이트가 Drive에서 2GB 원본을 자동으로 옮길 수는 없습니다. 원본 MP4/WebM 파일을 보유해야 하며, 해당 영상을 배포할 권한도 있어야 합니다.**

## 재생 및 보안

- 회원의 로그인·승인 상태는 메종 루미엘 서버에서 확인합니다.
- 승인된 재생 요청은 Cloudflare R2의 **짧게 유효한 전용 서명 URL**로 전달하며, 실제 영상 데이터는 Railway 서버를 통과하지 않습니다.
- 이미 발급한 서명 URL은 최대 약 2분 동안 공유·재사용될 수 있습니다. DRM이나 완전한 복제 방지가 아닙니다.
- 멤버를 제한·해제하면 **새 재생 요청은 서버에서 차단**하지만, 기존에 전달한 데이터와 이미 발급된 서명 URL까지 즉시 회수할 수는 없습니다.
- Google Drive로 등록된 다른 영상은 R2에 직접 옮기지 않는 한 기존 다운로드 한도 문제가 계속될 수 있습니다.
- 영상과 회원 개인정보는 GitHub에 업로드하지 않습니다.

## 문제가 생기면

- **버튼이 비활성화**: R2 연결 변수 4개를 등록하고 재배포한 뒤 관리자 새로고침.
- **업로드가 403/CORS로 실패**: 버킷 CORS AllowedOrigins의 실제 사이트 주소, 메서드 PUT, API 키의 읽기·쓰기 권한 확인.
- **R2 무료 용량 경고**: 저장 용량 확인 후 사용하지 않는 파일을 정리합니다. 무료 제공량의 월별 사용량은 Cloudflare R2 대시보드에서 확인합니다.
- **오디오만 재생되거나 검은 화면**: MP4 H.264/AAC 인코딩으로 다시 만들어 테스트합니다.

이 문서는 **선택형 기능 사용 설명서**이며, Cloudflare R2 계정·버킷·키 생성은 아직 수행되지 않았습니다.
