10. 짧게 미리듣기 → 전체 생성 → 결과 다운로드 순서로 사용합니다.

참조 음성
- GPT-SoVITS: 3~10초 음성과, 그 음성에서 실제로 말한 정확한 대사.
- CosyVoice: 3~30초 음성과, 그 음성에서 실제로 말한 정확한 대사.
- 배경음 없이 한 사람만 말하는 녹음, 파일당 10MB 이하를 사용하세요.

내 코랩과 내 작업
- 친구나 운영자의 코랩 주소를 공용으로 돌려 쓰는 방식이 아닙니다.
- 코랩을 새로 시작하면 새 주소가 생길 수 있으므로 새 주소를 붙여넣습니다.
- 주소는 현재 접속 화면에만 보관되며 운영자 공용 주소로 대체되지 않습니다.
- 참조 파일과 생성 결과는 접속 세션별 폴더에 분리됩니다.
- 사이트를 새로고침하거나 접속을 종료하면 작업 화면과 연결 설정이 초기화될 수 있습니다.
- 완성 파일은 작업 중 다운로드하세요. 계정별 영구 보관 기능은 없습니다.
- '내 연결·작업 지우기'는 현재 접속의 설정과 파일만 삭제합니다.
- 음성과 대사는 공유 사이트 서버를 거쳐 본인 코랩으로 전달됩니다.

코랩에서 직접 만들기
코랩 2번은 참조 음성 업로드, 3번은 직접 생성·미리듣기·WAV 다운로드입니다.
사이트 연결을 쓰지 않을 때는 4번을 실행하지 않아도 됩니다.

사용 중 참고
- 무료 코랩의 GPU와 사용 시간은 보장되지 않습니다.
- 무료 코랩은 외부 웹 화면을 통한 사용을 제한하며 연결이 종료될 수 있습니다.
  이 경우 코랩 3번 셀에서 직접 생성할 수 있습니다.
