# 🎙️ 대본 기반 화자별 자동 TTS 생성기 (Multi-Speaker Script TTS)

완성된 대본 속 **나레이션과 등장인물별 대사**를 자동으로 분리하여, 각 화자에게 어울리는 고품질 목소리(TTS)를 입히고 **전체 병합 오디오 및 자막(SRT/VTT)**까지 한 번에 제작해 주는 프로그램입니다.

---

## ✨ 주요 기능

1. **대본 자동 파싱 (화자/대사 자동 분리)**
   - `나레이션: 내용`, `[철수] 대사`, `영희: "대사"` 등 다양한 대본 형식을 완벽하게 자동 인식합니다.
   - 대본에서 등장하는 모든 인물을 중복 없이 추출하여 화자별 목록을 만듭니다.

2. **화자별 목소리 커스텀 설정**
   - 인물 및 나레이션마다 원하는 목소리(성별, 연령대, 분위기)를 자유롭게 지정할 수 있습니다.
   - 말하기 속도(속도 ±50%) 및 목소리 톤(피치 ±50Hz)을 세밀하게 조절 가능합니다.
   - 각 화자의 목소리를 즉시 들어볼 수 있는 **미리듣기(Preview)** 기능을 지원합니다.

3. **무음 간격이 조절된 전체 오디오 병합 (`full_audio.mp3`)**
   - 대사와 대사 사이의 자연스러운 호흡(무음 간격, 기본 0.5초)을 반영하여 하나의 완성된 오디오 파일로 병합합니다.

4. **영상 편집용 자막 파일 자동 생성 (`subtitles.srt`, `subtitles.vtt`)**
   - 음성 재생 길이에 맞춘 정확한 타임스탬프 기반 자막을 생성합니다. 프리미어, 파이널컷, 캡컷(CapCut), Vrew 등 영상 편집 프로그램에 바로 넣어서 작업할 수 있습니다.

5. **웹 UI (GUI) 및 CLI(명령어) 모두 지원**
   - 브라우저에서 마우스 클릭으로 직관적으로 사용하는 **웹 화면**과 대량 작업에 적합한 **터미널 명령어(CLI)**를 모두 지원합니다.

---

## 🚀 빠른 시작 방법

### 1. 웹 프로그램 실행 (추천)
바탕화면이나 탐색기에서 **`run_web.bat`** 파일을 더블 클릭하거나 터미널에서 다음 명령어를 실행합니다:

```bash
streamlit run app.py
```

실행하면 웹 브라우저가 자동으로 열립니다 (`http://localhost:8501`).

1. **대본 입력**: 대본을 직접 입력하거나 `.txt` 파일을 업로드한 뒤 **[화자 및 대사 분석하기]** 클릭.
2. **목소리 지정**: 감지된 화자별로 원하는 목소리를 선택하고 **[미리듣기]**로 확인.
3. **생성 및 다운로드**: **[전체 TTS 및 자막 일괄 생성 시작]** 클릭 후 완성된 오디오 재생 및 다운로드!

---

### 2. 터미널(CLI)로 일괄 실행

터미널이나 명령 프롬프트(CMD/PowerShell)에서 대본 파일을 직접 지정하여 실행할 수도 있습니다.

```bash
# 기본 실행
python main_cli.py --script sample_script.txt --output outputs/my_project

# 대사 간 무음 0.7초 설정 및 지문(괄호 속 지시문) 자동 제거 옵션
python main_cli.py --script sample_script.txt --output outputs/my_project --pause 700 --clean-stage
```

## 📝 지원하는 대본 작성 형식 예시

아래 형식들을 모두 지원하므로 편하신 방식으로 대본을 작성하시면 됩니다:

```text
나레이션: 어느 평화로운 숲속 마을에 새로운 아침이 밝아왔습니다.
민우: 오늘은 날씨가 정말 화창하네! 지수야, 우리 피크닉 갈까?
나레이션: 민우는 설레는 마음으로 가방을 챙기며 지수를 바라보았습니다.
지수: 정말 좋은 생각이야! 내가 맛있는 샌드위치를 준비해 올게.
```

- **대괄호형**: `[나레이션] ...` / `[민우] ...`
- **소괄호형**: `(나레이션) ...` / `(지수) ...`
- **따옴표형**: `민우 "오늘 날씨 좋다."`
- **지문 포함**: `지수: (웃으며) 정말 예쁘다.` (웹 화면 또는 `--clean-stage` 옵션으로 지문만 자동으로 제거하고 읽게 할 수 있습니다.)

## 📂 프로젝트 폴더 구조

```
nifty-mendel/
├── app.py                  # Streamlit 웹 UI 애플리케이션
├── main_cli.py             # 터미널용 일괄 실행 CLI 스크립트
├── run_web.bat             # 윈도우 원클릭 실행 배치 파일
├── requirements.txt        # 파이썬 필수 패키지 목록
├── sample_script.txt       # 테스트용 샘플 대본 파일
├── core/
│   ├── parser.py           # 대본 파싱 및 화자 분리 모듈
│   ├── tts_engine.py       # Edge-TTS 신경망 음성 합성 엔진
│   ├── audio_processor.py  # FFmpeg 기반 무음 삽입 및 오디오 병합
│   └── subtitle.py         # SRT 및 VTT 자막 파일 생성 모듈
└── outputs/                # 생성된 결과물 (개별 mp3, 전체 오디오, 자막)
```
