# 🎙️ 대본 기반 화자별 자동 TTS 생성기 (Multi-Speaker Script TTS)

현재 공유 사이트: **v2.9.61 · 캐글 FP32 가속·모델별 로그·중지 상태**. 최근 변경 사항은 아래 버전별 기록에 있습니다.

## v2.9.61 — 캐글 FP32 가속·모델별 로그·중지 상태

- 코지2·3 캐글 작업에 같은 고정 모델 리비전의 공식 FP32 ONNX와 TensorRT 10.13.3.9를 사용합니다. FP16/BF16/INT8/TF32 계산을 활성화하지 않으며 가중치·샘플링·flow 단계·화자·읽기 속도는 유지합니다. vLLM의 공식 export는 BF16으로 변환하므로 이번 경로에 사용하지 않습니다.
- 모델별 남은 대사가 12개 이상일 때 가속 엔진을 준비합니다. 짧은 미리듣기는 최초 변환 대기를 피하고 FP32 최적화로 시작합니다. 12개 기준은 설치 비용을 피하기 위한 정책이며 측정된 최적값이라는 뜻은 아닙니다.
- 같은 실행 환경의 GPU 두 개가 모델·하드웨어·드라이버·Torch·TensorRT·ONNX 해시가 일치하는 가속 파일을 공유합니다. 가속 준비 실패는 로그에 표시하고 원본 FP32로 진행합니다. 최초 변환에는 추가 시간이 걸리며 새 캐글 배치는 새 환경이므로 다시 준비합니다. 사용자가 노트북이나 모델 파일을 직접 다시 올릴 필요는 없습니다.
- 음향 변환은 기존 잠금 안에서 호출자의 CUDA 스트림으로 실행합니다. TensorRT 프로파일 범위를 벗어나면 해당 구간을 같은 원본 FP32 estimator로 처리하며 대사를 자르거나 계산 단계를 줄이지 않습니다. 가속 결과가 정상인지 기존 유한값·무음 검사로 확인하며 실제 음질 동일성/속도 향상은 아직 실측하지 않았습니다.
- 코지3에도 코지2의 불필요한 문자 예측 생략, 동일 규칙 샘플링, 구간별 메모리 재사용을 연결했습니다. 화자 준비·발음 계산·음향 대기·파형 계산 시간을 모델별 로그에 표시합니다. 두 모델의 로그 다운로드와 상태·완료 수를 따로 제공합니다.
- 작업 목록에 ‘중지 화면 열기’를 넣었습니다. 해당 캐글 작업을 열고 실행 중인 버전을 취소해야 실제 GPU가 멈춥니다. SDK CancelKernelSession은 숫자 session ID가 필요하지만 배치 SaveKernel/GetKernelSessionStatus는 이를 반환하지 않습니다. 노트북 ID나 상대 버전 번호를 session ID로 추측하거나 노트북을 삭제하지 않습니다. 사이트 단독 즉시 중지 API가 구현됐다는 의미가 아닙니다.
- Kaggle의 실제 CANCEL_REQUESTED/CANCEL_ACKNOWLEDGED 상태를 ‘중지 처리 중/중지 완료’로 처리합니다. 이전에는 이 값들을 GPU 대기로 잘못 분류할 수 있었습니다. 중지 후 실제 제공된 결과만 회수하며 저장 전 음성의 보존을 보장하지 않습니다. 완료와 중지가 겹친 경우 유효한 완료 결과를 우선합니다.
- 새 가속 코드는 새로 제출하는 작업부터 적용됩니다. 이미 실행 중인 작업의 코드는 교체하지 않습니다. 기존 코랩 실행 경로, GPU당 3개 생성+3개 준비, 최종 순번 합치기, MOV 기능은 유지합니다.
- 요청에 따라 테스트·컴파일 검사·프로젝트 import·로컬 앱 실행·실제 캐글 API 호출·음성 생성은 하지 않습니다. 배포용 노트북을 작성하는 패키징만 실행합니다.

## v2.9.45 · 코랩 유지 + CosyVoice 2·3 캐글 GPU 2개 옵션

기존 코랩 노트북·서버·연결·기본 생성 경로는 그대로 유지합니다.
선택 범위의 모든 화자가 CosyVoice 2 또는 3이면, 3번 생성 영역에서 **캐글 GPU 2개**를 추가로 선택할 수 있습니다.
사이트에서 캐글 노트북과 대본 ZIP을 받은 뒤, Kaggle의 **GPU T4 ×2 / Internet ON**에서 ZIP을 비공개 Input으로 추가하고 실행하세요.
자세한 단계는 `Kaggle_CosyVoice_Guide.txt`에 있습니다.

- `CosyVoice2_Kaggle_DualGPU.ipynb`: 코지2 전용
- `CosyVoice3_Kaggle_DualGPU.ipynb`: 코지3 전용
- `CosyVoice2_3_Kaggle_DualGPU.ipynb`: 코지2·3 혼합 대본

물리 GPU UUID를 지정한 독립 프로세스 두 개가 각각 기존 서버·모델을 실행합니다.
각 GPU는 한 대사씩 계산하고 완료 즉시 다음 대사를 가져옵니다. 여러 대사를 묶어 전부 끝나길 기다리는 방식이 아닙니다.
혼합 대본은 코지2를 두 GPU에서 생성한 뒤 모델을 내리고, 코지3를 두 GPU에서 생성합니다.
완료 결과는 대본 순번대로 WAV로 합친 뒤 MP3를 한 번 인코딩합니다. `complete_audio.zip`에는 전체 MP3 하나와 자막을 넣습니다.
중단되면 완료 WAV와 설정을 `resume.zip`에 보관하며, 누락 대사가 있으면 최종 음성을 만들지 않습니다.

모델·소스 버전과 FP32·기존 생성 설정을 유지하며, 기존 Colab 서버 파일은 수정하지 않습니다.
설치 환경과 모델은 `/tmp`, 저장할 결과는 `/kaggle/working`에 둡니다. 캐글 기본 Python 패키지는 별도 venv로 분리합니다.
외부 서버나 터널을 만들지 않으며, 사이트의 API 키·접속 주소는 대본 ZIP에 넣지 않습니다.
노트북에는 해당 버전 코드가 포함됩니다. 코드를 바꾸면 `python build_kaggle_notebooks.py`로 다시 묶습니다.
사용자 요청에 따라 이 변경에서는 테스트·실제 GPU 실행·새 음성 생성을 하지 않았습니다. 처리 시간과 음질은 실측하지 않았습니다.

완성된 대본 속 **나레이션과 등장인물별 대사**를 자동으로 분리하여, 각 화자에게 어울리는 고품질 목소리(TTS)를 입히고 **전체 병합 오디오 및 자막(SRT/VTT)**까지 한 번에 제작해 주는 프로그램입니다.

## ✨ 주요 기능

1. **대본 자동 파싱 (화자/대사 자동 분리)**
   - `나레이션: 내용`, `[철수] 대사`, `영희: "대사"` 등 다양한 대본 형식을 완벽하게 자동 인식합니다.
   - 대본에서 등장하는 모든 인물을 중복 없이 추출하여 화자별 목록을 만듭니다.

2. **화자별 목소리 커스텀 설정**
   - 인물 및 나레이션마다 원하는 목소리(성별, 연령대, 분위기)를 자유롭게 지정할 수 있습니다.
   - 말하기 속도(속도 ±50%) 및 목소리 톤(피치 ±50Hz)을 세밀하게 조절 가능합니다.
   - 각 화자의 목소리를 즉시 들어볼 수 있는 **미리듣기(Preview)** 기능을 지원합니다.

3. **무음 간격이 조절된 전체 오디오 병합 (`full_audio.mp3`)**
   - 대사와 대사 사이의 자연스러운 호흡(무음 간격, 기본 0.5초)을 반영하여 하나의 완성된 오디오 파일로 병합합니다.

4. **영상 편집용 자막 파일 자동 생성 (`subtitles.srt`, `subtitles.vtt`)**
   - 음성 재생 길이에 맞춘 정확한 타임스탬프 기반 자막을 생성합니다. 프리미어, 파이널컷, 캡컷(CapCut), Vrew 등 영상 편집 프로그램에 바로 넣어서 작업할 수 있습니다.

5. **웹 UI (GUI) 및 CLI(명령어) 모두 지원**
   - 브라우저에서 마우스 클릭으로 직관적으로 사용하는 **웹 화면**과 대량 작업에 적합한 **터미널 명령어(CLI)**를 모두 지원합니다.

## 🚀 빠른 시작 방법

### 1. 웹 프로그램 실행 (추천)
바탕화면이나 탐색기에서 **`run_web.bat`** 파일을 더블 클릭하거나 터미널에서 다음 명령어를 실행합니다:

```bash
streamlit run app.py
```

실행하면 웹 브라우저가 자동으로 열립니다 (`http://localhost:8501`).

1. **대본 입력**: 대본을 직접 입력하거나 `.txt` 파일을 업로드한 뒤 **[화자 및 대사 분석하기]** 클릭.
2. **목소리 지정**: 감지된 화자별로 원하는 목소리를 선택하고 **[미리듣기]**로 확인.
3. **생성 및 다운로드**: **[전체 TTS 및 자막 일괄 생성 시작]** 클릭 후 완성된 오디오 재생 및 다운로드!

---

### 2. 터미널(CLI)로 일괄 실행

터미널이나 명령 프롬프트(CMD/PowerShell)에서 대본 파일을 직접 지정하여 실행할 수도 있습니다.

```bash
# 기본 실행
python main_cli.py --script sample_script.txt --output outputs/my_project

# 대사 간 무음 0.7초 설정 및 지문(괄호 속 지시문) 자동 제거 옵션
python main_cli.py --script sample_script.txt --output outputs/my_project --pause 700 --clean-stage
```

## 📝 지원하는 대본 작성 형식 예시

아래 형식들을 모두 지원하므로 편하신 방식으로 대본을 작성하시면 됩니다:

```text
나레이션: 어느 평화로운 숲속 마을에 새로운 아침이 밝아왔습니다.
민우: 오늘은 날씨가 정말 화창하네! 지수야, 우리 피크닉 갈까?
나레이션: 민우는 설레는 마음으로 가방을 챙기며 지수를 바라보았습니다.
지수: 정말 좋은 생각이야! 내가 맛있는 샌드위치를 준비해 올게.
```

- **대괄호형**: `[나레이션] ...` / `[민우] ...`
- **소괄호형**: `(나레이션) ...` / `(지수) ...`
- **따옴표형**: `민우 "오늘 날씨 좋다."`
- **지문 포함**: `지수: (웃으며) 정말 예쁘다.` (웹 화면 또는 `--clean-stage` 옵션으로 지문만 자동으로 제거하고 읽게 할 수 있습니다.)

# CosyVoice 3 별도 서버 · v2.9.42

CosyVoice 2와 3은 서로 다른 GPU 런타임·접속 주소·화자 설정으로 사용합니다.
기존 `CosyVoice_Colab_API.ipynb`와 버전 2 서버는 유지합니다.
버전 3은 `CosyVoice3_Colab_API.ipynb`에서 **1 설치 → 2 서버 준비 → 4 사이트 연결** 순서로 실행합니다.
사이트의 **CosyVoice 3 · 내 코랩 주소**에 새 주소를 넣고, 화자 카드에서 버전 3을 선택하세요.
현재 실행 중인 버전 2의 주소를 버전 3 주소로 덮어쓰지 않습니다.

버전 3에는 남성 10명·여성 10명의 VCTK 공개 참고 음성 목록이 있습니다.
기본 음성은 영어 원본 음색으로 한국어를 합성하는 교차 언어 방식입니다.
Gemini의 성우·음성이나 Qwen의 합성 샘플을 사용하지 않습니다.
**내 한국어 녹음**에서 3~30초 WAV/FLAC과 실제 녹음 대사를 등록할 수도 있습니다.
원본 음색·성별과 스타일은 별도로 선택합니다. 스타일 변경은 화자 ID를 바꾸지 않습니다.
인물의 성별이 불명확하면 카드에 확인 안내가 표시됩니다.

버전 2·버전 3·Gemini의 대기열은 독립적이며, 완료 결과는 번호순으로 MP3 하나로 합칩니다.
버전 3은 GPU 계산 한 개와 HTTP 요청 대기·파일 전송을 분리합니다.
새 모델의 GPU 동시 생성 성능이나 음질 우위를 측정한 것으로 표시하지 않습니다.
모델은 Fun-CosyVoice3-0.5B-2512 / FP32 / 공식 샘플링·생성 단계를 사용합니다.

무료 Colab에서 두 GPU 런타임을 동시에 배정받을 수 있다고 보장하지 않습니다.
외부 웹 연결이 제한되면 사이트에서 **CosyVoice 3 코랩 대본 받기**로 받은 ZIP을 코랩 3번에 올려 직접 생성합니다.
서버 감독은 실제 서버·터널 상태를 확인하는 기능으로 Colab 사용 시간 제한을 변경하지 않습니다.

### v2.9.48 / 캐글 409 충돌 복구

생성 요청에서 409 또는 응답 유실이 발생하면 고유 작업 주소의 실제 실행 상태를
자동 조회합니다. GPU 생성 요청은 재전송하지 않습니다. 상태 API의 404/409만으로
새 생성을 허용하지 않고, 작업 메타데이터에서도 404를 확인해야 제한을 해제합니다.
존재하는 작업의 상태가 불명확하면 기존 작업을 보존하고 재확인을 안내합니다.
이전 버전에 남은 409 오류는 연결된 같은 계정으로 한 번 자동 복구 조회합니다.

완료 상태와 결과 준비 시점의 차이를 처리하도록 결과 수신의 일시적 오류를 제한된
횟수로 재시도합니다. 종료가 확인된 실패 작업은 결과가 없어도 생성 제한을 해제합니다.
HTTP 응답의 알려진 오류 메시지 필드를 보존해 요청 단계·응답 코드·실제 사유를
표시합니다. 인증정보, 요청 본문, 응답 헤더 및 서명된 URL은 표시하지 않습니다.
409 화면만으로 실제 캐글 충돌 사유를 확정할 수 없으므로 계정 문제로 단정하지 않습니다.

기존 코랩 및 코지2·3 추론·목소리·정밀도 설정은 변경하지 않았습니다.
요청에 따라 테스트·컴파일·앱 실행·실제 합성은 하지 않았으며, 계정에서의 생성 성공은 미확인입니다.

분리합니다. 지문 제거를 켜도 감정은 별도 보존합니다. 감정 표시를 화자로 잘못 파싱하던
중첩 대괄호 처리도 수정했습니다. 한 줄에는 첫 감정만 적용하며, 중간 또는 복수 표시에는
화면 안내를 표시합니다. 표 저장은 대본에도 태그를 기록하고, 미분석 수정이 있으면 먼저
분석하도록 안내하여 입력창의 초안을 덮어쓰지 않습니다. 감정 대본 다운로드도 제공합니다.

코지2·3의 기존 스타일 지시 필드와 Gemini의 연기 지시에 연결하므로 코랩 서버 재설치나
신규 API 키가 필요하지 않습니다. 캐글 자동/수동 생성과 코지3 코랩 내보내기도 같은
지시를 사용합니다. 지원하지 않는 엔진은 감정을 무시하지 않고 안내 후 생성을 막습니다.
강도와 감정은 캐시 식별에 반영하며, 감정 없는 기존 대사의 캐시 키는 유지합니다.
대사 순번 합치기·동시 생성·RPM·모델 설정은 바꾸지 않습니다. Fish Audio API 연동이나
그 모델과 동일한 음질을 의미하지 않습니다.

요청에 따라 테스트·컴파일·로컬 앱 실행·음성 생성은 하지 않았습니다. 소스와 공식
문서를 검토했으며 감정 표현·발음·화자 유사도는 실제 합성으로 확인하지 않았습니다.

### v2.9.53 — 공유 사이트 캐글 코지2·3 동시 생성

- 혼합 대본은 코지2와 코지3를 각각 별도 캐글 배치 작업으로 제출합니다. 각 작업은 기존 T4 x2 설정으로 실행되며 실제 동시 시작은 계정 한도/자원 배정에 따릅니다.
- GPU마다 대사 하나를 끝내면 다음 대사를 즉시 처리합니다. 한 모델의 실패가 다른 모델을 중단시키지 않습니다.
- 모델별 원본 WAV와 순번/해시를 받아 공유 사이트에서 대본 순서대로 합칩니다. 중간 MP3를 만들지 않고 최종 MP3를 192kbps로 한 번만 인코딩합니다. 기존 화자·감정·스타일·속도·FP32·추론 설정은 유지합니다.
- 모델별 진행/오류/작업 링크, 두 작업을 함께 복구하는 JSON 다운로드/불러오기를 제공합니다. 복구·재확인은 기존 상태/결과만 조회하며 GPU 작업을 중복 제출하지 않습니다.

### v2.9.54 — GPU당 3개 생성·다음 3개 사전 준비

- 캐글의 각 GPU에서 모델 하나를 공유하는 생성 작업 3개와 다음 요청 3개를 유지합니다. GPU 2개인 작업 하나에서 최대 6개 생성 + 다음 6개 준비입니다. 코지2·코지3 별도 캐글 작업 제출과 최종 순번 합치기를 유지합니다.

- 완료 CPU 오디오는 크기가 제한된 별도 저장 큐로 전달합니다. 다음 계산은 WAV 저장·코디네이터의 결과 복사/영수증 저장을 기다리지 않습니다. 원본 PCM/WAV를 기존 순번으로 합치고 최종 MP3만 한 번 인코딩합니다.
- 코지3의 캐글 전용 경로는 요청별 CUDA stream과 UUID 캐시를 사용합니다. 고정 소스의 기존 비스트리밍 LLM·token2wav 연산을 그대로 호출하며, 코지2와 같이 공유 flow/vocoder를 잠그고 CUDA 완료까지 기다립니다. 모든 음향 계산이 세 개씩 동시에 실행된다는 의미는 아닙니다.
- FP32·모델/참고 음성·샘플링·생성 단계·속도·화자 설정을 유지합니다. 오류나 메모리 부족이면 새 요청을 중단하고 이미 계산 중인 결과를 저장합니다. 자동으로 정밀도를 낮추거나 무제한 재생성하지 않습니다.

- 요청에 따라 테스트·컴파일/import·로컬 앱 실행·모델 로딩·실제 GPU/TTS 생성은 하지 않았습니다. 코드 검토와 노트북 파일 재패키징만 수행했습니다. 처리 속도와 실제 음질은 측정하지 않았습니다.

### v2.9.55 — 음성 연결부 잡음 방지

- 캐글 단일/혼합 생성과 공유 사이트의 일반 합치기에 동일한 PCM 연결 처리를 적용합니다. 경계 값이 0에서 벗어난 채 끝나거나 시작하는 채널에만 최대 2ms의 완만한 감쇠를 적용해 연결부의 클릭음을 줄입니다. 이미 0에 가까운 경계는 그대로 복사합니다.
- 원본 파일과 대사 내부는 보존하고, 대사 시작·끝을 삭제하거나 다른 대사와 겹치지 않습니다. 음높이·속도·전체 음량을 변경하는 필터를 사용하지 않습니다. 원본에서 이미 발생한 기계음·끊긴 발음을 복원하는 기능은 아닙니다.
- 같은 형식의 WAV는 변환 없이 연결합니다. MP3 또는 형식이 다른 음성은 각각 PCM으로 풀어 연결하고 최종 MP3를 192kbps로 한 번만 인코딩합니다. 자막은 실제 연결한 샘플 수로 계산합니다.
- 선언된 길이보다 덜 저장된 WAV는 최종 파일로 게시하지 않고 원본을 보관합니다. 연결은 작은 버퍼로 수행하며 캐글 최종 WAV도 완성된 뒤 교체합니다.
- GPU당 3개 생성·다음 3개 준비, 모델·화자·스타일·FP32·생성 설정과 코랩 연결 방식을 유지합니다. 새 합치기부터 적용되며, 이미 받은 완성 파일이나 이미 제출한 캐글 실행 파일은 자동 변경하지 않습니다.
- 요청에 따라 테스트·컴파일/import 검사·앱 실행·실제 음성 생성은 하지 않았습니다. 소스 검토와 캐글 노트북 재패키징만 수행했으며 실제 청취 품질은 확인하지 않았습니다.

### v2.9.56 — 투명 자막 MOV 다운로드
