# 🎙️ AI Voice Studio PRO - 지인용 초간단 사용 설명서

본 프로그램은 소설/시나리오 속 대사를 AI가 자동으로 분석하여, 
성우 목소리로 생생한 오디오 드라마와 싱크 자막(SRT)을 만들어주는 스튜디오입니다.

---

## 🚀 1. 최초 1회 실행 방법

1. 컴퓨터에 **Python(파이썬)**이 설치되어 있는지 확인합니다.
   - 만약 없다면 [https://www.python.org/downloads/](https://www.python.org/downloads/) 에서 설치
   - ⚠️ 설치 첫 화면 맨 아래 **[Add Python to PATH]** 체크박스를 꼭 체크하세요!

2. 폴더 안의 **`실행하기.bat`** 파일을 더블클릭합니다.
   - 최초 실행 시 필요한 AI 패키지를 약 1~2분간 자동으로 세팅합니다.
   - 세팅이 끝나면 인터넷 브라우저 창(Chrome/Edge)에 스튜디오 화면이 자동으로 열립니다!

---

## 🎙️ 2. 제공되는 3가지 음성 엔진

1. **👑 Supertonic 3 (로컬 완전 무료)**:
   - 내 컴퓨터 안에서 완전 무료로 0.5초 만에 생성되는 하이브 수퍼톤의 초고속 한국어 모델입니다.
   - 인터넷 연결이나 별도 키 없이도 노트북에서 쌩쌩하게 돌아갑니다.

2. **⚡ Gemini 3.1 Flash (스튜디오 성우급 감정 연기)**:
   - 구글 최신 Gemini 멀티모달 음성 엔진으로, 웃음, 슬픔, 속삭임 등 감정을 연기합니다.
   - 사이드바에 Google AI Studio 무료 API 키를 넣으면 바로 작동합니다.

3. **🎙️ AI 목소리 복제 (구글 무료 16GB GPU 코랩 연동)**:
   - 친구나 유명인의 5초짜리 샘플 목소리를 그대로 복제합니다.
   - 사이드바 상단의 **[🔥 CosyVoice & XTTS 코랩 열기]** 또는 **[🎙️ GPT-SoVITS 코랩 열기]**를 누르고,
     구글 코랩 화면에서 [모두 실행]을 누른 뒤 나오는 주소를 복사해 프로그램에 넣으면 끝!

---

## 💡 꿀팁
- 대본 입력창에 소설 원문을 복사해 넣고 **[✨ 소설 대본 자동 변환]**을 누르면 알아서 화자별 대사로 쪼개집니다.
- 하단의 **[🎙️ 전체 오디오 일괄 생성]**을 누르면 대화 오디오와 싱크 자막(SRT/VTT)이 한 번에 완성됩니다!
