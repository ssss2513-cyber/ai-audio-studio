CosyVoice 2·3 — 공유 사이트에서 캐글 음성 만들기 / v2.9.49

공유 사이트: https://voice-studio.streamlit.app/

이제 공유 사이트에서 생성 버튼을 누르고, 완성된 음성도 공유 사이트에서 받습니다.
캐글 GPU 2개가 음성 계산을 담당합니다. 기존 코랩도 계속 사용할 수 있습니다.
앞서 드린 그림 안내서는 ‘캐글에서 직접 실행하는 수동 방식’입니다.
새 자동 연결에는 노트북 가져오기, 대본 ZIP 업로드, 캐글 Run All이 필요 없습니다.

1. 처음 한 번, 내 캐글 연결

   공유 사이트를 새로고침합니다. 적용 버전 v2.9.49를 확인하세요.
   왼쪽 ‘🚀 코지2·3 · 캐글 연결’을 엽니다.
   ‘음성을 계산할 GPU’에서 ‘캐글 GPU 2개’를 고릅니다.

   이미 발급받은 토큰을 사이트의 ‘캐글 API 토큰’ 칸에 붙여넣습니다.
   토큰이 없는 경우에만 https://www.kaggle.com/settings/api 에서 발급받습니다.
   ‘내 캐글 연결’을 누르고 ‘캐글 연결됨 · 내아이디’가 나타나는지 확인합니다.

   kaggle.json이 있다면 ‘kaggle.json 파일 등록’을 선택해 올려도 됩니다.
   이 파일은 캐글 API 설정의 Legacy API Credentials → Create Legacy API Key에서 받습니다.
   접속한 사람마다 자기 캐글 계정을 연결합니다.
   인증정보는 현재 접속에만 보관하며, 대본·노트북·음성 결과에 넣지 않습니다.

2. 공유 사이트에서 대본과 목소리 설정

   평소처럼 대본을 분석하고 화자마다 목소리, 성별, 스타일, 속도를 고릅니다.
   캐글 생성은 선택한 대사의 모든 화자가 CosyVoice 2 또는 3일 때 지원합니다.
   코지2는 참고 음성과 실제 녹음 대사를 등록합니다.
   코지3는 기본 목소리 20종 또는 내 한국어 녹음을 사용할 수 있습니다.
   왼쪽 기본 엔진만 바꿔도 기존 화자 설정은 자동으로 덮어쓰지 않습니다.

3. 공유 사이트에서 생성

   ‘3. TTS 오디오 및 자막 생성’으로 내려갑니다.
   전체 또는 원하는 대사 구간을 고릅니다.
   ‘이 사이트에서 음성 생성 · 캐글 GPU 2개’를 누릅니다.

   사이트가 내 캐글 계정에 대본·참고 음성을 비공개로 보내고 생성 작업을 시작합니다.
   화면에서 전송 → GPU 대기 → 설치·모델 준비 → 생성 → 결과 수신을 확인합니다.
   한 GPU가 먼저 끝나면 다음 대사를 바로 맡습니다.
   코지2·3 혼합은 코지2를 두 GPU로 처리한 다음 코지3를 처리하고 순번대로 합칩니다.
   원래 모델, 화자, 스타일, 속도, FP32 정밀도와 추론 설정을 유지합니다.

   새 캐글 작업마다 GPU 배정, 환경 설치, 모델 준비 시간이 필요합니다.
   미리듣기 버튼도 이 방식으로 생성하므로 한 대사라도 준비 시간이 필요합니다.
   캐글의 진행 기록이 늦게 반영되면 사이트의 완료 개수도 늦게 바뀔 수 있습니다.
   실제 완료 시간이나 특정 속도를 보장하지 않습니다.

4. 공유 사이트에서 결과 받기

   ‘캐글 생성 진행·완성 음성’에 완료 안내가 나타납니다.
   ‘완성 음성 들어보기’로 듣습니다.
   ‘전체 대사 MP3 한 파일 받기’로 대본 순서대로 합친 MP3를 받습니다.
   SRT/VTT 자막과 MP3+자막 ZIP도 사이트에서 받을 수 있습니다.

5. 끊기거나 중단된 경우

   제출이 끝난 작업은 사이트 창을 닫아도 캐글에서 계속 실행됩니다.
   캐글 사용 한도·런타임 제한까지 해제되는 것은 아닙니다.
   사이트의 ‘내 캐글 작업 열기’ 주소를 보관해두세요.

   사이트에 새로 접속했다면 같은 캐글 계정을 연결하고,
   왼쪽 ‘이전 캐글 작업 불러오기’에 그 작업 주소를 넣습니다.
   작업을 다시 생성하지 않고 현재 상태나 저장된 결과를 가져옵니다.

   ‘상태·결과 다시 확인’도 같은 작업의 상태와 다운로드만 확인합니다.
   업로드·생성 요청의 응답이 끊겼다고 같은 작업을 자동 중복 제출하지 않습니다.

   401·403 오류만으로 토큰 만료라고 판단하거나 토큰을 계속 재발급받지 마세요.
   ‘현재 토큰으로 연결 다시 확인’은 입력된 토큰을 그대로 사용합니다.
   작업 조회가 거부되면 계정 인증과 작업 등록 여부를 구분해서 확인합니다.
   계정 인증이 정상이고 작업 자체가 없다는 404 응답까지 확인되면
   이전 작업 때문에 막혀 있던 생성 제한을 해제합니다.
   작업 접근 여부가 불명확하면 기존 작업을 보존합니다.
   ‘캐글 오류 상세 보기’에서 현재 오류와 최초 생성 요청 오류를 각각 볼 수 있습니다.

   409 충돌이 나면 실제 작업이 시작됐는지 자동으로 확인합니다.
   실행 중이면 진행 상황을 이어받고, 결과 저장이 늦으면 다운로드만 다시 시도합니다.
   작업 자체가 등록되지 않은 것을 확인하면 새 생성을 막던 상태를 해제합니다.
   그때 위의 생성 또는 미리듣기 버튼을 다시 누르세요.
   계속 오류가 나면 ‘캐글 오류 상세 보기’에서 발생 단계와 캐글 응답을 확인합니다.
   409라는 숫자만으로 API 키 오류나 GPU 한도 초과라고 단정하지 않습니다.
   기존 접속의 409 오류도 업데이트 뒤 계정이 연결되어 있으면 한 번 자동 확인합니다.

   일부 생성 후 오류가 나고 완료분이 저장됐다면 사이트가 resume.zip도 받아둡니다.
   같은 접속에서 대본·설정을 유지하고 다시 생성하면 이 완료분을 재사용합니다.
   대본이나 설정을 변경하면 새 작업으로 생성합니다.
   완료 파일도 새로 만들기를 켜면 기존 완료분을 사용하지 않습니다.

   실행을 중지하려면 ‘내 캐글 작업 열기’에서 현재 실행 중인 작업을 중지합니다.
   캐글이 결과를 저장하기 전에 강제로 종료되면 저장하지 못한 대사는 복구할 수 없습니다.

6. 코랩 사용

   왼쪽 ‘음성을 계산할 GPU’를 ‘기존 코랩 연결’로 바꾸면 기존 방식입니다.
   기존 코랩 노트북, 접속 주소, 모델과 생성 방식은 유지했습니다.
   Gemini 등 다른 엔진과 섞인 전체 대본은 기존 연결 방식을 사용하세요.

계정의 휴대폰 인증과 GPU 사용 가능 시간은 캐글에서 확인해야 합니다.
이번 변경에서는 요청에 따라 테스트·컴파일·모델 실행·실제 음성 생성을 하지 않았습니다.
