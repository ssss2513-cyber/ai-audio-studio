AI Voice Studio — GPT-SoVITS / CosyVoice 코랩 시작
================================================

사용할 코랩
- GPT-SoVITS v4: GPT_SoVITS_Colab_API.ipynb
- CosyVoice 2: CosyVoice_Colab_API.ipynb

공유 사이트에서 시작
1. 사이트 왼쪽에서 GPT-SoVITS 또는 CosyVoice를 선택합니다.
2. '내 구글 코랩 연결'의 '코랩 바로 열기'를 누릅니다.
3. 본인 구글 계정으로 로그인합니다.
4. 런타임 → 런타임 유형 변경 → T4 GPU를 선택합니다.
5. '1. 설치 및 실행' 셀 왼쪽 ▶를 누르고 준비 완료를 기다립니다.
6. 4번 셀의 '프로그램에 연결'을 체크하고 ▶를 누릅니다.
7. 나온 '프로그램 연결 주소' 전체를 사이트의 해당 엔진 주소 칸에 넣습니다.
8. 연결 확인 → 대본·참조 음성 입력 → 짧게 미리듣기 → 전체 생성 순서로 사용합니다.

코랩 파일로 받은 경우
https://colab.research.google.com/ 에서 파일 → 노트북 업로드로 엽니다.
그 뒤 위의 4번부터 진행하면 됩니다.

코랩 안에서 직접 만들기
- 1번: 설치 및 모델 준비
- 2번: 참조 음성 업로드
- 3번: 참조 음성의 실제 대사와 새로 읽힐 대사를 입력하고 생성·미리듣기·다운로드
- 4번: 사이트 연결이 필요할 때만 실행

참조 음성
- GPT-SoVITS: 3~10초, 파일당 10MB 이하
- CosyVoice: 3~30초, 파일당 10MB 이하
- 두 엔진 모두 참조 음성에서 실제로 말한 대사를 정확하게 입력해야 합니다.
- 배경음 없이 한 사람만 또렷하게 말하는 WAV/MP3를 권장합니다.

이번 설치 수정
- GPT: 공식 NLTK 사전 파일을 고정된 버전으로 받아 크기와 SHA-256을 확인합니다.
  자동 사전 목록 요청이 프록시 보안 검사에 막혔던 설치 경로를 교체했습니다.
- CosyVoice: Whisper 설치 시 별도 빌드 환경에도 setuptools 버전 제한을 적용합니다.
  기존 실행 환경에만 적용되던 제한 때문에 pkg_resources가 없어지는 문제를 수정했습니다.
- 실패하면 실제 오류가 셀 아래에 나오며, 같은 요청을 자동 반복하지 않습니다.
- 긴 코드 줄 때문에 코랩 편집기가 멈추던 설치 셀을 정리했습니다.

설치가 멈췄다면
실패한 1번 셀 맨 아래의 실제 오류 내용을 확인하세요.
내용이 부족하면 마지막 '오류가 날 때만 실행' 셀의 ▶를 누르고 출력을 보내주세요.
같은 런타임에서 재실행하면 이미 받은 모델 파일을 재사용합니다.
런타임을 삭제하거나 새로 시작하면 설치·다운로드가 다시 필요할 수 있습니다.

연결과 사용 시간
코랩 종료 후에는 새 연결 주소를 사용하세요. 주소의 /v1/… 부분까지 전부 복사합니다.
GPT-SoVITS는 끝의 /tts도 포함합니다. 개인 접속 키가 있으므로 주소를 다른 사람에게 보내지 마세요.
무료 코랩의 GPU 할당과 사용 시간은 보장되지 않습니다.
외부 웹 화면 사용으로 연결이 종료되면 코랩 2·3번 셀에서 직접 만들 수 있습니다.
실제 Colab GPU에서의 음성 생성과 품질은 별도 확인이 필요합니다.
