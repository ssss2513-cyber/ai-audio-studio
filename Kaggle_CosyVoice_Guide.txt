CosyVoice 2·3 캐글 GPU 2개 사용법 — v1.0.0 / 공유 사이트 v2.9.45

코랩은 그대로 사용할 수 있습니다. 캐글은 추가 선택입니다.
코랩 주소와 서버를 다시 연결할 필요 없이 기존 방식으로 계속 사용할 수 있습니다.

1. 공유 사이트에서 준비
   https://voice-studio.streamlit.app/
   대본을 분석하고 화자별 엔진, 목소리, 스타일, 참고 음성을 설정합니다.
   ‘3. TTS 오디오 및 자막 생성’에서 ‘캐글 GPU 2개’를 선택합니다.
   캐글 노트북과 ‘캐글용 대본·목소리 받기’ ZIP을 둘 다 받습니다.
   캐글용 대본 내보내기는 코랩 서버 연결 없이도 가능합니다.
   미리듣기는 기존 코랩 연결을 사용합니다.

2. 캐글에서 준비
   https://www.kaggle.com/code
   New Notebook → File → Import Notebook에서 받은 .ipynb를 불러옵니다.
   Settings → Accelerator → GPU T4 x2, Internet ON을 선택합니다.
   GPU 선택이 잠겨 있으면 계정의 전화번호 인증·GPU 사용 가능 잔량을 확인합니다.
   Add Input → Upload에서 대본 ZIP을 비공개 데이터셋으로 추가합니다.
   ZIP을 캐글이 자동으로 풀어도 plan.json을 찾아서 읽습니다.
   같은 대본의 원본 ZIP과 압축 해제본을 동시에 넣지 마세요.

   코지2만 사용: CosyVoice2_Kaggle_DualGPU.ipynb
   코지3만 사용: CosyVoice3_Kaggle_DualGPU.ipynb
   코지2·3 혼합: CosyVoice2_3_Kaggle_DualGPU.ipynb

3. 실행
   Run All 또는 1 → 2 → 3 → 4번 셀을 순서대로 실행합니다.
   1번: 실행 코드 준비
   2번: 독립 환경 설치와 모델 다운로드
   3번: 두 GPU로 실제 대사 생성 후 순번대로 합치기
   4번: 다운로드 링크
   캐글의 서버 주소를 만들거나 사이트에 붙여넣을 필요는 없습니다.
   캐글 작업 진행 상황과 결과는 캐글 화면에서 확인합니다.

4. 결과 받기
   full_audio.mp3: 대사 전체를 합친 음성 한 파일
   complete_audio.zip: 위 MP3 하나와 SRT/VTT 자막
   full_audio.wav: MP3 압축 전 전체 음성
   resume.zip: 완료된 개별 대사와 설정을 담은 이어하기 파일
   링크가 열리지 않으면 Output → voice_studio_results → 작업 폴더에서 받습니다.

5. 중단 후 이어하기
   같은 캐글 세션: 3번을 다시 실행하면 완료된 대사는 재사용합니다.
   새 세션: resume.zip을 보관했다가 원본 대본 Input 대신 비공개 Input으로 넣습니다.
   새 세션에서는 1번부터 다시 실행합니다.
   세션이 완전히 삭제되기 전에 Output이나 resume.zip을 저장하세요.
   갑자기 세션이 종료되면 생성 중이던 대사와 아직 저장하지 않은 Output은 잃을 수 있습니다.
   ‘완료 파일도 새로 만들기’를 켜서 사이트에서 새로 받은 대본은 음성 캐시를 재사용하지 않습니다.

6. 실행 방식
   GPU마다 기존 모델을 각각 하나씩 올리고 대사를 한 개씩 계산합니다.
   한 GPU가 먼저 끝나면 다른 GPU를 기다리지 않고 다음 대사를 맡습니다.
   코지2·3 혼합 대본은 엔진별로 두 GPU를 사용한 뒤 원래 대본 순서대로 합칩니다.
   엔진·모델·FP32 정밀도·생성 단계·화자·스타일·속도를 낮춰서 빠르게 만들지 않습니다.
   첫 설치와 모델 로딩은 생성 시간과 별도로 필요합니다.
   실제 속도는 대사 길이와 GPU에 따라 달라지며 2배 또는 특정 완료 시간을 보장하지 않습니다.
   이번 배포에서는 요청에 따라 실제 GPU 실행, 음성 생성, 테스트를 수행하지 않았습니다.

7. 브라우저를 닫고 실행하기
   Input과 GPU 설정을 저장한 후 Save Version → Save & Run All을 선택합니다.
   깨끗한 세션에서 전체 셀을 실행하므로 필요한 파일은 반드시 Input으로 추가해야 합니다.
   완료 파일은 저장된 버전의 Output에서 받습니다.
   실행 시간과 GPU 사용량은 Kaggle의 계정·서비스 제한을 따릅니다.

코랩 사용: 사이트의 ‘기존 코랩 연결’을 선택하면 이전 방식으로 사용합니다.
기존 코랩 노트북·서버·연결 주소와 화자 설정은 유지합니다.
