공유 사이트 운영자 적용 안내 — 개인 코랩 방식
============================================
이 저장소는 공유 사이트에서 실행할 프로그램 소스입니다.
이용자는 사이트에서 자기 코랩 파일만 받아 연결합니다.
GPT 발음 사전 설치 수정과 CosyVoice 빌드 의존성 수정을 포함합니다.
코랩 엔진은 GPT-SoVITS와 CosyVoice 두 가지입니다.

적용 순서
1. 검토한 수정 커밋을 운영 사이트가 연결된 GitHub main 브랜치에 반영합니다.
2. Streamlit Community Cloud에서 업데이트 후 앱을 재시작합니다.
   배포 저장소와 app.py 실행 경로는 유지합니다.
3. 직접 실행하는 서버는 'streamlit run app.py'를 사용합니다.
   requirements.txt의 Python 패키지와 packages.txt의 ffmpeg/libsndfile1이 필요합니다.
4. 새 접속에서 버전 'v2.8 · 코랩 설치 수정'과 '내 구글 코랩 연결'이 보이는지 확인합니다.
5. 이용자들에게 공유 사이트 주소와 README_지인사용법.txt의 안내를 전달합니다.

운영 방식
- 운영자가 코랩을 대신 켜거나 공용 GPU 주소를 제공하지 않습니다.
- GPT-SoVITS/CosyVoice 주소는 접속자별 세션 상태에 저장합니다.
- 이 공유 버전에서는 서버에 설정된 GPT_SOVITS_URL·Gemini 키를 이용자에게 자동 배포하지 않습니다.
- 기존 기능에서 Gemini를 선택하면 이용자가 자신의 API 키를 입력합니다.
- 기본 엔진은 GPT-SoVITS입니다. CosyVoice는 왼쪽 엔진 선택에서 바꿉니다.
- 코랩에 있는 이용자의 GPU가 음성을 생성하고, 공유 서버는 파일 전달·변환·병합·다운로드를 처리합니다.
  따라서 사이트 서버에도 CPU·메모리·디스크·전송량은 필요합니다.

사용자 파일 처리
- outputs/web_sessions 아래 임의의 접속 식별자별 폴더를 사용합니다.
- 완성본을 공용 static 주소로 복사하지 않으며 정적 파일 제공을 끕니다.
- 결과는 현재 세션의 Streamlit 다운로드 버튼으로 제공합니다.
- 서버 로컬 파일·폴더를 입력해서 읽는 UI는 제거하고 참조 음성 업로드를 사용합니다.
- '내 연결·작업 지우기'는 해당 세션 폴더만 지웁니다.
- 로그인 기반 영구 보관이나 자동 만료 삭제는 포함되어 있지 않습니다.
  중도 이탈한 세션 폴더는 서버에 남을 수 있으므로 보관 정책에 맞춰 디스크를 관리하세요.
- 업데이트 직후 기존 공용 다운로드 주소가 계속 노출되지 않도록 서버를 반드시 재시작하세요.

연결 주소
- 함께 제공된 수정 코랩의 https://…trycloudflare.com/v1/… 주소만 받습니다.
- GPT-SoVITS는 끝에 /tts까지 포함합니다.
- 코랩 종료/재연결 시 이용자가 새 주소를 입력합니다.
- 본인의 개인 코랩을 각각 연결하는 방식이므로 공용 GPU 대기열은 추가하지 않았습니다.

확인 범위
운영 반영 전 코드 문법과 앱 화면을 확인하세요.
실제 Colab GPU 설치·음성 생성은 본인 코랩에서 별도 확인이 필요합니다.
수정 브랜치나 파일을 전달하는 것만으로 운영 중인 사이트가 업데이트되지는 않습니다.

이용자에게 알릴 사항
무료 코랩은 외부 웹 화면을 통한 사용이 제한되고 세션이 종료될 수 있습니다.
사이트 연결이 안 되면 코랩 2·3번 셀에서 직접 생성하도록 안내하세요.
