# 준영 클래스 · Rose Atelier 1.0

아이보리, 더스티 로즈, 샴페인 골드로 새로 제작한 회원 전용 영상관입니다. 커다란 왕관이나 과한 반짝임 대신 넓은 여백, 아치형 그래픽, 절제된 글씨와 모션을 사용합니다.

**실행 가능한 새 프로그램의 소스입니다. GitHub 등록이 공개 서비스 배포를 뜻하지 않습니다. 기존 사이트의 영상·회원·키를 복사하거나 기존 사이트를 삭제하는 코드는 없습니다.**

## 화면부터 보기

이 폴더에서 `python build_preview.py`를 실행하면 단일 파일 `preview.html`이 만들어집니다. 브라우저로 열어 홈·클래스·회원가입·관리자 화면을 확인할 수 있습니다. 미리보기는 가상 데이터만 사용하며 실제 가입·업로드·명단 저장을 하지 않습니다. 실제 개인정보를 입력하지 마세요.

## 포함된 기능

- 이름·휴대폰 번호·비밀번호(최소 8자) 가입. 문자·PASS·실명인증 없음.
- 관리자 승인 기본. 자동 승인은 정상 신규 가입에만 적용.
- 시청 승인 / 승인 취소 / 이용 제한 / 제한 해제 / 멤버 해제 / 멤버 복원 / 개인정보 영구 삭제 분리.
- 서버에서 영상 요청과 전송 블록마다 현재 권한 확인. 제한 시 기존 로그인 세션 폐기.
- 재생 화면은 3초 간격으로 권한을 확인하고 확인 실패 시 정지합니다.
- MP4·WebM, 파일당 최대 5 GiB. 8 MiB 조각 전송, SHA-256 검증, 재시도, 같은 파일 재선택 후 이어올리기.
- 영상 정보·배치 순서·썸네일 수정, 공개/비공개, 휴지통, 복원, 제목 재입력 후 영구 삭제.
- 재생 속도 / 10초 뒤로 / 이어보기 / 전체화면.
- 회원 검색·상태 필터·페이지 이동·연락처 상세 열람·명단 CSV·처리 기록.
- 이름과 번호 암호화, 비밀번호 Argon2id 해시, HttpOnly 세션 쿠키, CSRF·출처 검사.
- 휴대폰 하단 메뉴, 모션 끄기, 기기 동작 줄이기 설정 반영.

## 실행 방법

### Windows

Python 3.11 이상을 준비한 뒤 `start_windows.bat`을 실행합니다. 처음에는 운영자 이메일과 비밀번호를 입력합니다. 비밀번호 입력 문자는 화면에 표시되지 않습니다. 창을 닫으면 로컬 프로그램도 종료됩니다. 해당 BAT는 Windows 실기기에서 검증하지 않았습니다.

### 직접 실행

```bash
cd junyeong-classroom-luxe
python -m venv .venv
# macOS/Linux: source .venv/bin/activate
# Windows: .venv\Scripts\activate
pip install -r requirements.txt
python manage.py create-admin
python -m uvicorn app:app --host 127.0.0.1 --port 8000 --workers 1
```

브라우저에서 `http://127.0.0.1:8000`을 엽니다. 관리자는 `/admin` 또는 하단의 운영자 메뉴입니다. 운영자 이메일을 아는 것만으로 관리자 권한을 얻을 수 없습니다. **운영자 계정은 로컬 관리 명령에서만 생성**됩니다.

문의 이메일 기본값은 `ssss2513@gmail.com`입니다. 이 이메일은 자동 생성된 관리자 로그인 계정이 아닙니다. 비밀번호·관리자 계정·기존 운영 키를 하드코딩하지 않았습니다.

## 운영 순서

1. 운영자 계정 생성 → 관리자 로그인.
2. 서비스 설정에서 문의 연락처와 개인정보 보관 안내 검토. 관리자 승인 또는 신규 자동 승인 선택.
3. 영상 관리 → 새 영상 올리기 → 파일·제목·제공 권한 확인 → 업로드.
4. 완료 영상은 비공개입니다. 미리 재생해 내용과 호환성을 확인한 뒤 공개합니다.
5. 회원 관리 → 상세·권한 관리 → 시청 승인. 제한·해제 시 사유와 안내를 확인합니다.

기본값은 영상관 오픈, 자동 승인 꺼짐입니다. 운영자 초기 계정이 없으면 신규 가입을 받지 않습니다.

## 저장·배포 경계

기본 데이터 저장 위치는 이 폴더의 `data/`이며 GitHub에 포함하지 않습니다. DB, `secret.key`, 원본 영상을 별도로 보호해야 합니다. 키를 잃으면 암호화된 회원 연락처를 복호화할 수 없습니다. 서비스를 정지한 상태에서 데이터와 키를 보호된 백업으로 보관하거나 SQLite 백업 API를 사용하세요.

외부 운영 시 HTTPS, 명시적인 `PUBLIC_ORIGIN`, 충분한 영구 디스크, 백업·복구 계획이 필요합니다. 예제는 **단일 프로세스·단일 영구 디스크** 방식입니다. 여러 워커·복수 서버·무상태 서버리스에 그대로 배포하지 마세요. `.env.example`은 설명 파일이며 자동으로 읽지 않습니다. 환경변수는 실행 전에 지정합니다.

GitHub Pages만으로 이 Python 프로그램의 회원 처리와 대용량 영상 저장을 운영하는 구성은 아닙니다. 현재 단계에서는 새 공개 서버를 배포하지 않았습니다.

## 알아둘 제한

- 기존 사이트 삭제·데이터 이전은 수행하지 않았습니다.
- 번호 소유 확인을 하지 않으므로 타인 번호 사용이나 다른 번호 재가입까지 동일인으로 판별할 수 없습니다.
- 다운로드 버튼 숨김은 DRM이 아닙니다. 이미 전달된 데이터나 녹화물을 회수할 수 없습니다.
- 재생 화면 확인 간격은 3초이지만 절전·통신 상태에 따라 정지 시점은 달라집니다. 서버는 새 요청과 전송 블록마다 다시 검사합니다.
- CDN, 외부 버킷, 자동 영상 인코딩은 포함하지 않습니다. MP4(H.264/AAC)를 우선 사용하고 실제 기기 재생을 확인하세요.
- 업로드는 컨테이너 헤더·조각 해시·크기 검증이며 코덱 정상성까지 검사하지 않습니다.
- 이어올리기 파일 대조는 크기·파일명·수정 시각·앞뒤 샘플 해시입니다. 전체 원본 동일성의 사전 증명은 아닙니다.
- 개인정보 보관 문구 자체가 자동 삭제 작업은 아닙니다. 운영 정책에 맞게 검토하세요. 휴지통도 자동 영구 삭제하지 않습니다.
- `python manage.py cleanup`은 7일 이상 미완료 업로드와 만료 세션만 정리합니다. 대용량 전송이 없을 때 실행하세요.
- 원본 2 GiB의 조각과 최종 파일 조립에 약 4 GiB 이상의 여유 공간이 필요합니다.
- 로컬 검증은 운영 환경 전체 보안 감사나 실제 다중 사용자 부하 시험이 아닙니다.

글꼴은 CSS에서 Google Fonts를 선택적으로 요청합니다. 폰트 파일은 동봉하지 않으며, 연결이 차단되면 기기 글꼴을 사용합니다.

## 야담 제작 도구 공유 탭

`/#tools`에서 야담 대본 생성기 V13.7, 이미지 프롬프트 생성기 2.7.2 수정본 r1, 검증기 V11.20 전체 ZIP을 내려받습니다.
PC 상단 메뉴와 휴대폰 하단 메뉴에 진입점이 있으며, ‘이 페이지 공유’로 해당 탭 주소를 공유합니다.
대본 생성기·검증기는 `00_먼저읽기`, 이미지 프롬프트 생성기는 `README_처음읽기.txt`에 Claude 프로젝트 설정 방법이 있습니다. 이미지 프롬프트 생성기는 2026-10-04의 2.7.2 수정본 r1 전체 64파일을 원본 ZIP 그대로 제공합니다.

목록은 공개하고 다운로드는 기존 회원 승인·사이트 이용 권한으로 확인합니다. 파일은 공개 정적 폴더 밖의 `shared-tools/`에 두며, 서버에서 등록된 파일 ID만 허용합니다. 회원·영상 데이터와 인증 설정은 변경하지 않습니다.

패키지 업데이트: `shared-tools/`의 ZIP과 `shared_tools.py`의 파일명·버전·설명을 함께 변경하고 배포합니다. 대본 생성기는 2026-10-20 V13.8.1로 갱신했습니다. 인트로 분리, 작품별 옛이야기 도입, 최초 강도 선택 규칙을 포함하며 다른 패키지의 등록일은 각 항목을 따릅니다.
