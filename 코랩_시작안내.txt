GPT-SoVITS v4 발음/참조 음성 처리 수정 (2026-09-28)
================================================
1. 프로그램을 종료하고, ZIP 안 nifty-mendel 폴더의 내용물을 기존 app.py가 있는 폴더에 덮어씁니다.
2. GPT_SoVITS_Colab_API.ipynb를 코랩에 새로 업로드합니다.
   기존 코랩의 패치된 서버가 실행 중이면 그 세션을 종료하고 새 런타임에서 시작하세요.
3. T4 GPU 선택 → 1번 설치 셀 실행 → 'v4 준비 완료 · 48kHz' 확인.
4. 2번에서 참조 음성을 올리고, 3번에서 직접 생성해 먼저 들어보세요.
5. 프로그램과 연결하려면 4번 '프로그램에 연결' 체크 후 실행합니다.
   출력된 /v1/…/tts 주소 전체를 프로그램의 GPT-SoVITS API 주소에 붙여넣습니다.
6. 인물 카드에서 '기본 생성 설정으로 복원'을 누르고 참조 대사를 확인합니다.
   처음에는 속도 1.0, Temperature 1.0, 생성 단계 32로 짧은 문장을 비교하세요.

참조 음성 준비
- 3~10초, 한 사람, 배경음과 효과음 없이 또렷한 음성.
- 10초가 넘으면 문장이 끝나는 곳에서 직접 잘라 별도 파일로 등록하세요.
- '참조 오디오 실제 대사'는 그 파일에서 말한 모든 단어와 정확히 일치해야 합니다.
- 자동 추출 결과는 오타가 있을 수 있습니다. 직접 듣고 수정한 내용이 우선입니다.
- 너무 짧거나 긴 참조 음성, 빈 참조 대사는 오류를 표시하고 생성을 중지합니다.

이번 수정
- v4라는 화면 표시와 달리 v2 기본 모델을 사용하던 코랩 설정을 v4로 명시.
- 공식 v4 체크포인트, GPT 체크포인트, 48kHz 보코더 조합 지정.
- 한국어 발음 변환 오류를 숨기는 패치와 peft 무력화 패치 제거.
- 긴 참조 음성의 자동 절단/강제 음량 확대/자동 전사 우선 적용 제거.
- 업로드 파일이 그대로인데 수동 대사가 자동 인식 결과로 덮이는 문제 수정.
- 40자마다 쉼표를 삽입하던 처리를 제거하고 공식 문장부호 분할 사용.
- 공식 API 기본 샘플링 값으로 기본값 수정; 속도 1.0; v4 생성 단계 선택 추가.
- 미리듣기는 WAV로 저장; 전체 생성과 동일한 음성 설정 전달.
- 단일 생성 요청, 오류 전달, 정상 WAV 확인, 저장 실패 시 기존 파일 보존.
- CosyVoice + XTTS 코랩과 엔진은 앞서 전달한 버전 그대로 포함.

확인 범위와 남은 확인
- Python/노트북 문법, 참조 길이 거부, 대사 보존, WAV/MP3 전달, 중복 요청 방지를 확인했습니다.
- 실제 모델 대신 임시 파형을 쓰는 서버로 연결 처리만 확인했습니다.
- 이 환경에서 Colab 설치, 실제 GPU 추론, 청취 음질은 확인하지 못했습니다.
- 음질 문제가 계속되면 참조 파일 + 실제 생성 파일 + 생성 대사 + 코랩 마지막 로그를 함께 확인해야 합니다.
- 생성 시간이 초과되면 자동 재시도하지 않습니다. 코랩 로그를 먼저 확인하세요.

CosyVoice 2 + XTTS v2 통합본 V2

[기존 폴더에 적용]
프로그램을 종료합니다. ZIP을 풀고 안의 nifty-mendel 폴더를 엽니다.
그 안의 내용물을 기존 app.py가 있는 프로젝트 폴더에 복사해 덮어씁니다.
기존 core 폴더에도 새 core의 파일이 같은 경로로 들어가야 합니다.
프로그램을 다시 켭니다.

이번에 바뀐 실행 파일은 다음 5개입니다.
- app.py
- core/tts_engine.py
- core/cosy_colab_client.py
- colab_server.py
- CosyVoice_XTTS_Colab_API.ipynb

[코랩에서 실행]
1. https://colab.research.google.com/ 를 엽니다.
2. 파일 → 노트북 업로드에서 CosyVoice_XTTS_Colab_API.ipynb를 선택합니다.
   별도 다운로드한 CosyVoice_Colab_수정본.ipynb도 같은 통합본입니다.
3. 런타임 → 런타임 유형 변경 → T4 GPU → 저장을 선택합니다.
   이전 코랩 음성 서버가 실행 중이라면 종료하고 새 통합본을 실행하세요.
4. 1번 셀에서 'CosyVoice + XTTS' 또는 원하는 엔진 하나를 고릅니다.
   XTTS를 선택했다면 바로 위 모델 이용 조건을 읽고 확인 항목을 직접 체크합니다.
5. 1번 ▶를 누릅니다. 처음에는 모델과 패키지 다운로드에 시간이 걸립니다.
   두 엔진은 별도 환경에 차례로 설치됩니다. 각 엔진의 '준비 완료'를 기다립니다.
6. 2번 셀에서 한 사람이 말하는 3~30초 WAV/MP3를 업로드합니다.
7. 3번 셀에서 엔진, 새로 읽힐 대사, 속도를 선택하고 실행합니다.
   CosyVoice: 참고 음성에서 실제로 말한 대사도 입력해야 합니다.
   XTTS: 참고 음성만 있으면 되며, 실제 대사 입력은 비워도 됩니다.
8. 생성된 WAV를 듣고 다운로드합니다.
   대사나 엔진만 바꿀 때는 3번만 다시 실행합니다.

[PC 프로그램과 연결]
1. 코랩 4번 셀에서 '프로그램에 연결'을 체크하고 실행합니다.
2. CosyVoice 2 주소와 XTTS v2 주소가 따로 나옵니다.
3. 프로그램 왼쪽의 각 엔진 접속 주소 칸에 해당 주소 전체를 넣습니다.
   뒤에 붙은 /v1/… 부분까지 모두 포함하세요.
4. 각 연결 버튼을 눌러 모델 준비 상태를 확인합니다.
5. 한 엔진만 쓰려면 해당 엔진을 선택합니다.
   인물마다 다른 엔진을 쓰려면 '하이브리드 (인물별 자유 선택)'를 선택합니다.
6. 인물별 참고 음성을 등록한 뒤 미리듣기 또는 전체 생성을 실행합니다.

두 엔진을 설치해 놓고 번갈아 사용할 수 있습니다.
GPU 음성 생성은 한 번에 하나씩 실행합니다.
다른 작업이 진행 중이면 완료 후 실행하라는 메시지가 나옵니다.
실패한 요청을 자동으로 계속 반복하지 않습니다.
두 엔진 주소를 서로 바꿔 넣으면 연결 오류를 표시합니다.
주소에는 임시 접속 키가 포함되므로 다른 사람에게 공유하지 마세요.
코랩 런타임이 종료되면 다시 준비하고 새 주소를 넣어야 합니다.

공개 XTTS v2 모델과 생성물에는 Coqui Public Model License가 적용됩니다.
이 라이선스는 비상업용만 허용합니다. 수익화 유튜브 영상 등 상업용 사용에는
별도 사용 권한이 필요합니다. 설치 전 코랩에서 조건을 직접 확인하게 했습니다.
생성물을 다른 사람에게 전달할 때 모델 이용 조건 링크도 함께 전달하세요.

[이번 추가 사항]
- XTTS 전용 설치, 모델 로딩, 준비 상태 및 한국어 합성 API 추가.
- 코랩 안의 엔진 선택, 설치된 엔진별 외부 연결 주소 출력.
- XTTS 미리듣기와 전체 생성에 속도 설정 적용.
- 참고 음성 실제 대사는 CosyVoice에만 필수.
- 엔진별 패키지 환경과 GPU 동시 작업 충돌 분리.
- 엔진을 잘못 연결하거나 서버가 실패하면 오류를 표시하고 종료.

[확인 범위와 오류 안내]
파일 구문과 엔진별 연결 코드를 확인했습니다.
이번 XTTS 추가본의 실제 Colab GPU 설치·음성 생성은 실행하지 않았습니다.
오류가 나면 마지막 '오류가 날 때만 실행' 셀의 출력 내용을 보내주세요.
Colab의 GPU 할당과 사용 시간은 계정 상태에 따라 달라집니다.
무료 환경에서는 외부 웹 화면을 통한 콘텐츠 생성 시 세션이 종료될 수 있습니다.
https://research.google.com/colaboratory/faq.html
