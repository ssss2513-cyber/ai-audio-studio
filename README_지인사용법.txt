Qwen3-TTS 1.7B CustomVoice 추가 · 앱 v2.9.35 / Qwen 코랩 v1.0.0
==========================================================

1. 공유 사이트 https://voice-studio.streamlit.app/ 를 새로고침합니다.
2. 왼쪽 ‘Qwen3-TTS 설정 · 내 코랩 연결’에서 Qwen 코랩 v1.0.0을 엽니다.
3. 코랩: 런타임 → 런타임 유형 변경 → T4 GPU를 선택합니다.
4. 1번 설치 → 2번 모델 준비를 실행하고 ‘준비 완료’를 기다립니다.
5. 공유 사이트에서 생성하려면 코랩 4번을 실행합니다. 출력된 프로그램 연결 주소 전체를
   공유 사이트의 ‘Qwen3-TTS · 내 코랩 주소’에 넣고 ‘Qwen 연결 확인’을 누릅니다.
6. ‘전체 화자를 Qwen3-TTS로 변경’을 누르고 화자별 성별·보이스·스타일을 확인합니다.
   추가 스타일 지시에는 ‘차분하고 따뜻하게, 문장 끝을 또렷하게’처럼 적을 수 있습니다.
7. 미리듣기 또는 전체 생성을 누릅니다. 전체 생성 완료 후 대사 순서대로 합친 MP3를 받습니다.

무료 코랩 안에서 직접 생성하는 방법
- 무료 코랩은 외부 웹 화면 위주의 이용이 제한됩니다. GPU 배정과 이용 시간도 보장되지 않습니다.
- 사이트에서 모든 화자를 Qwen으로 바꾼 뒤 ‘Qwen 코랩 직접 생성용 대본 받기’를 누릅니다.
- 코랩 1번 → 2번 → 3번 순서로 실행하고 내려받은 JSON 파일을 올립니다. 4번은 필요 없습니다.
- 목소리·스타일·순서를 그대로 사용하며 최종 MP3 하나와 자막을 만듭니다.
- 런타임이 유지되는 동안 같은 JSON의 완료 음성을 재사용합니다. 결과는 바로 다운로드하세요.

Qwen 참고
- 정확히 Qwen3-TTS-12Hz-1.7B-CustomVoice 모델을 사용합니다. 0.6B로 자동 교체하지 않습니다.
- 모델은 한 번만 GPU에 올립니다. GPU 네이티브 배치 최대 2개 / 사이트 대기 요청 최대 4개입니다.
- 메모리 부족 시 정밀도와 모델은 유지하고 배치 크기만 1개로 줄입니다.
- 기본 모델 정밀도는 T4에서 FP32, 네이티브 BF16 지원 GPU에서 BF16입니다. 강제 FP16·양자화는 하지 않습니다.
- Gemini·Chirp·Cosy 생성 대기열과 분리해 실행하며, 개별 WAV를 저장한 뒤 최종 MP3로 합칩니다.
- 한국어 전용 기본 보이스는 여성 Sohee입니다. 다른 보이스도 한국어를 읽지만 발음·억양은 다를 수 있습니다.
- 스타일과 대사는 별도 입력으로 전달합니다. 감정·연령 연기의 결과를 보장하거나 목소리 성별을 자동으로 바꾸지 않습니다.
- Qwen은 전용 코랩에서 실행하세요. Cosy/GPT를 같은 GPU에 동시에 올리면 메모리가 부족할 수 있습니다.
- 각 이용자는 본인 코랩을 실행합니다. 연결 주소의 개인 접속 코드를 다른 사람에게 보내지 마세요.
- 기존 Cosy/GPT 코랩 파일과 Gemini 요청 간격은 이번 추가에서 바꾸지 않았습니다.
- 요청에 따라 실행 테스트, 컴파일, 샘플 음성 생성은 하지 않았습니다. 소스 검토만 수행했습니다.

공식 자료: https://github.com/QwenLM/Qwen3-TTS
코랩 제한 안내: https://research.google.com/colaboratory/faq.html

AI Voice Studio — Chirp 3 HD / 기존 개인 코랩 이용 안내
====================================
이용자는 프로그램 ZIP이나 Python을 설치할 필요가 없습니다.

Google Chirp 3 HD 사용하기 — 코랩 불필요
1. https://voice-studio.streamlit.app/ 에 접속합니다.
2. Google Cloud 프로젝트에 결제 계정을 연결하고 Cloud Text-to-Speech API를 사용 설정합니다.
   https://console.cloud.google.com/apis/library/texttospeech.googleapis.com
3. 같은 프로젝트의 사용자 인증 정보 → 사용자 인증 정보 만들기 → API 키에서 키를 발급합니다.
   API 제한에는 Cloud Text-to-Speech API를 지정합니다.
   서버가 요청하므로 웹사이트/HTTP 리퍼러 제한 키는 사용하지 않습니다.
   https://console.cloud.google.com/apis/credentials
4. 사이트 왼쪽 ‘Google Chirp 3 HD 설정’의 API 키 칸에 입력합니다.
5. 대본을 넣고 화자를 분석합니다. 기존 대본은 ‘전체 화자를 Google Chirp 3 HD로 변경’을 누릅니다.
6. 각 화자의 남성/여성, 보이스, 읽기 속도를 확인하고 전체 생성 버튼을 누릅니다.
7. 최대 4개를 연속 생성하며, 모두 완료되면 대사 번호순으로 MP3 한 파일과 자막을 만듭니다.

- Gemini API 키나 코랩 서버 주소를 등록할 필요가 없습니다.
- 월 100만 자 무료 한도를 초과하면 Google Cloud에서 요금이 부과됩니다.
- 미리듣기·재생성·다른 프로그램 사용량도 합산됩니다. 사이트는 Google 전체 월 사용량을 조회하지 않습니다.
- API 키는 접속 세션에만 보관하며 다른 방문자에게 공유하거나 작업 파일에 저장하지 않습니다.
- 생성 중 화면 조작으로 같은 대사를 자동 재요청하지 않습니다. 완료 파일을 재사용해 이어서 생성할 수 있습니다.
- 큰 대사는 한국어 UTF-8 길이에 맞춰 나누고 WAV 원음을 순서대로 연결합니다.
- Gemini의 감정·나이 스타일 지시문은 Chirp에 전달하지 않습니다. 선택한 보이스와 속도를 적용합니다.
- API 사용 설정/키/결제 권한 오류는 해당 설정을 고친 뒤 이어서 생성하세요.
- Chirp 연결은 v2.9.34에서 추가했습니다. 요청에 따라 실행 테스트와 실제 음성 생성은 수행하지 않았습니다.

공식 안내

CosyVoice / GPT-SoVITS — 개인 코랩 이용 안내
아래 목소리 복제 엔진은 이용자마다 본인 구글 코랩을 연결합니다.

1. 공유 사이트에 접속합니다.
2. 왼쪽에서 GPT-SoVITS v4, CosyVoice 2 중 사용할 엔진을 선택합니다.
3. '내 구글 코랩 연결'에서 사용할 엔진의 '코랩 바로 열기'를 누릅니다.
4. 본인 구글 계정으로 로그인합니다. 파일로 받았다면 파일 → 노트북 업로드로 엽니다.
5. 런타임 → 런타임 유형 변경 → T4 GPU 선택.
6. 코랩 1번 설치 셀 왼쪽 ▶를 눌러 실행합니다.
7. '준비 완료'가 나오면 4번 셀의 프로그램 연결 항목을 체크하고 실행합니다.
8. 출력된 '프로그램 연결 주소' 전체를 복사해 사이트의 해당 엔진 주소 칸에 넣습니다.
   GPT-SoVITS는 /v1/…/tts, CosyVoice는 /v1/… 끝부분까지 복사합니다.
9. '연결 확인'을 누른 뒤 대본과 참조 음성을 등록합니다.
10. 짧게 미리듣기 → 전체 생성 → 결과 다운로드 순서로 사용합니다.

참조 음성
- GPT-SoVITS: 3~10초 음성과, 그 음성에서 실제로 말한 정확한 대사.
- CosyVoice: 3~30초 음성과, 그 음성에서 실제로 말한 정확한 대사.
- 배경음 없이 한 사람만 말하는 녹음, 파일당 10MB 이하를 사용하세요.

내 코랩과 내 작업
- 친구나 운영자의 코랩 주소를 공용으로 돌려 쓰는 방식이 아닙니다.
- 코랩을 새로 시작하면 새 주소가 생길 수 있으므로 새 주소를 붙여넣습니다.
- 주소는 현재 접속 화면에만 보관되며 운영자 공용 주소로 대체되지 않습니다.
- 참조 파일과 생성 결과는 접속 세션별 폴더에 분리됩니다.
- 사이트를 새로고침하거나 접속을 종료하면 작업 화면과 연결 설정이 초기화될 수 있습니다.
- 완성 파일은 작업 중 다운로드하세요. 계정별 영구 보관 기능은 없습니다.
- '내 연결·작업 지우기'는 현재 접속의 설정과 파일만 삭제합니다.
- 음성과 대사는 공유 사이트 서버를 거쳐 본인 코랩으로 전달됩니다.

코랩에서 직접 만들기
코랩 2번은 참조 음성 업로드, 3번은 직접 생성·미리듣기·WAV 다운로드입니다.
사이트 연결을 쓰지 않을 때는 4번을 실행하지 않아도 됩니다.

사용 중 참고
- 무료 코랩의 GPU와 사용 시간은 보장되지 않습니다.
- 무료 코랩은 외부 웹 화면을 통한 사용을 제한하며 연결이 종료될 수 있습니다.
  이 경우 코랩 3번 셀에서 직접 생성할 수 있습니다.
