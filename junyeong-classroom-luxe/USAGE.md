# 운영 안내

## 영상 올리기

관리자 로그인 → 영상 관리 → 새 영상 올리기. 파일 선택, 제목 입력, 제공 권한 확인 후 업로드를 시작하세요. 완료되면 비공개로 등록됩니다. 재생을 확인한 뒤 공개하기를 누르세요.

파일당 최대 5 GiB이며 8 MiB씩 전송합니다. 기기를 켜고 화면을 유지하세요. 진행률·용량·남은 시간 추정값이 표시됩니다.

## 끊겼을 때 이어올리기

일시정지는 완료된 조각을 보관합니다. 영상 관리의 이어올리기 대기에서 같은 원본 파일을 선택하면 남은 조각을 전송합니다. 업로드 취소는 임시 조각을 삭제합니다. 탭이나 컴퓨터를 닫으면 전송이 계속되지 않습니다.

## 회원 승인·제한·해제

회원 관리에서 검색하거나 상태를 골라 상세·권한 관리를 누릅니다. 전체 번호 열람은 기록됩니다.

- 시청 승인: 대기 회원을 승인합니다.
- 승인 취소: 승인 대기로 변경하고 기존 접속을 종료합니다.
- 이용 제한: 사유 입력 후 차단합니다. 제한 해제는 승인 대기로 복귀합니다.
- 멤버 해제: 사유와 회원 이름 재입력으로 확인한 뒤 자격·접속을 해제합니다.
- 멤버 복원: 승인 대기로 복귀합니다. 다시 승인해야 시청합니다.
- 개인정보 영구 삭제: 멤버 해제 이후 별도 표시됩니다. 복구할 수 없습니다.

서버 저장에 성공한 후 목록을 다시 조회합니다. 다른 화면에서 변경된 경우 새로고침 후 처리하세요. 자동 승인은 기존 제한·해제 회원을 되살리지 않습니다.

## 영상 숨김·삭제

비공개와 휴지통은 원본을 유지하고 시청을 막습니다. 휴지통에서 복원하면 비공개입니다. 영구 삭제는 제목 재입력이 필요하며 원본 파일을 삭제합니다.

## 비밀번호 분실

운영자는 정당한 계정 소유자인지 별도로 확인해야 합니다. 단순히 번호를 적었다는 이유로 소유권을 인정하지 마세요. 운영자만 접근할 수 있는 실행 환경에서 `python manage.py reset-password`로 재설정할 수 있습니다. 재설정하면 접속은 종료되지만 승인·제한 상태는 유지됩니다.

## 기존 사이트

이번 소스 제작으로 기존 사이트·영상·회원 데이터를 삭제하거나 이전하지 않았습니다. 옛 사이트의 비밀번호·암호화 키를 복사하지 않았습니다.
