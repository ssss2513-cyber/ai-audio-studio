# 대본 생성 이력 — 최근 7일 중복 회피용

이 파일은 과거 원고 전문이 아닌 작품별 비교 기록이다. 메인 지침은 01번 하나이며 이 파일은 데이터다.

## 관리 정보
- schema_version: 1
- timezone: Asia/Seoul
- updated_at_kst: UNKNOWN
- history_coverage: UNKNOWN
- coverage_start_kst: UNKNOWN
- coverage_end_kst: UNKNOWN
- coverage_note: 초기 빈 서식. 이전 대화에서 생성한 작품의 목록·원고는 아직 이 파일에 반영되지 않음.

## 작품 기록

등록된 실제 작품 없음. 아래 양식은 입력 방법이며 작품으로 세지 않는다.
접근 가능한 실제 원고·팩트시트에서만 기록을 추가한다. 날짜·반전·결말을 지어내지 않는다.
최근 7일 전 기록도 삭제하지 않고, 비교할 때 last_generated_at_kst로 기간을 추린다.
같은 작품 수정은 같은 work_id의 기록을 갱신하고 다른 작품 기록은 남긴다.
기존 기록에 구조 항목이 없으면 읽을 수 있는 실제 팩트시트·원문에서 확인한 값만 추가한다. 확인할 수 없으면 UNKNOWN으로 두며 예전 기록을 빈 양식으로 덮지 않는다. 구조가 같다는 이유만으로 중복으로 판정하지 않고 실제 사건 지문을 비교한다.

## 기록 양식 — 실제 값으로 작성 후 위 작품 기록에 추가

각 작품은 아래처럼 한 블록으로 적는다. 7칸 지문은 각각 원인·행동·결과가 드러나는 1~2문장이다.
이름·소품만 적거나 모든 작품을 "착한 사람이 악인을 이김"으로 압축하지 않는다.

## 계속 사용하는 방법

새 작품의 첫 문장은 main_opening_phrase에 기록된 접근 가능한 직전 작품과 다른 옛이야기 표현으로 고릅니다. 실제 배경·시대·인물은 유지하며 기록이 없으면 이전 표현을 지어내지 않습니다. 이 빈 양식으로 이미 쌓인 작품 이력을 덮지 않습니다.

대본을 완성하면 Claude가 누적 내용을 담은 이 파일의 갱신본을 다른 결과와 함께 제공한다.
프로젝트 파일 자동 갱신이 실제로 되지 않는 환경에서는, 그 갱신본으로 프로젝트의 같은 이름 파일을 교체한다.
새 채팅에서도 이력이 있어야 지난 작품을 비교할 수 있다. 빠진 원고가 있으면 그 원고나 실제 지문을 추가해 비교 범위를 넓힌다.
``자동으로 모든 이전 대화를 기억한다``거나 ``이 파일만으로 유튜브 중복 정책 통과가 보장된다``고 해석하지 않는다.
