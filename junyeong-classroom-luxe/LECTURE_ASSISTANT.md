# 메종 루미엘 강의 비서

기존 Google Drive 원본과 메종 회원 계정을 사용하는 누적 강의 질의응답 기능입니다.

## 사용 순서

1. 메종 운영자 계정으로 로그인하고 **강의 비서 → AI 설정**을 엽니다.
2. Gemini API 키를 입력하고 연결 확인 후 저장합니다. 기존 Drive 연결용 서비스 계정과 별개입니다.
3. 기존 Drive 폴더에 MP4/WebM 강의를 올립니다.
4. **강의 분석 → Drive 영상 불러오기 → 새 강의 모두 분석**을 누릅니다.
5. **질문 가능**으로 표시된 강의부터 답변에 사용됩니다. 새 강의 분석 중에도 이전 강의로 질문할 수 있습니다.
6. 수강생은 같은 사이트의 **강의 비서**에서 질문합니다. 근거 카드를 누르면 기존 플레이어가 해당 시간에서 열립니다.

## 처리와 저장

- 원본은 Drive에 그대로 유지합니다. 서버가 인증된 범위 요청으로 읽어 5분 구간을 한 개씩 만들며, 구간 파일은 `/tmp/maison-lecture-ai`에 임시로 저장한 뒤 삭제합니다.
- 구간은 Google Gemini Files API로 전달됩니다. 처리 후 삭제를 요청합니다. API 사용량에 따라 비용이 발생할 수 있습니다.
- 분석 결과, 검색 색인, 진행률은 기존 영구 볼륨의 `lecture-ai/library.sqlite3`에 저장합니다. 서버 재시작 뒤에도 보존됩니다.
- 6시간 영상은 기본 72구간입니다. 구간별 완료 기록을 저장하고 재시작 또는 이어하기 때 완료된 구간은 건너뜁니다.
- 음성과 1초 간격 화면을 함께 분석합니다. 빠르게 지나가는 화면, 작은 글씨, 불명확한 음성은 누락될 수 있으며 출처 시간은 근사치입니다.
- 임시 공간 또는 영구 공간이 부족하면 중단하고 관리자에게 표시합니다. 분석 자료도 강의 수에 따라 공간을 사용합니다.
- 원본 변경을 진행 중 또는 이어하기 시 발견하면 중단합니다. Drive 원본을 수정했다면 **다시 분석**으로 해당 강의 기록을 갱신해 주세요.
- **다시 분석**은 그 강의의 기존 분석만 교체합니다. Drive 원본은 삭제하지 않습니다.
- **색인 보완**은 영상 분석을 반복하지 않고 저장된 기록의 의미 검색 색인만 보완합니다.

## 권한과 운영

- 기존 로그인, 관리자 권한, 승인 상태, 강의 공개 상태, CSRF 검사를 사용합니다.
- 일반 회원은 공개 강의만 검색할 수 있습니다. 비공개·휴지통 자료는 검색 단계부터 제외하며 답변 반환 전에 권한을 다시 검사합니다.
- AI 키는 기존 서버 암호화 키로 암호화해서 저장하며 브라우저로 다시 반환하지 않습니다. 환경변수 `GEMINI_API_KEY`가 설정되면 우선 사용합니다.
- 하나의 서버 프로세스와 하나의 분석 작업자를 사용합니다. Uvicorn workers와 Railway replica 수는 1을 유지합니다.
- 화면을 닫은 뒤에도 분석을 계속하려면 Railway 자동 절전은 해제되어 있어야 합니다.
- 대화는 현재 화면 메모리에만 유지합니다. 분석 자료는 영구 저장됩니다.

## 이번 검증

격리된 임시 데이터베이스에서 권한/CSRF, 키 암호화, 새 강의 누적, 중단 후 이어하기,
비공개 자료 검색 제외, 답변 중 권한 변경, 잘못된 출처 차단을 확인했습니다.
짧은 합성 영상으로 실제 HTTP 범위 요청과 FFmpeg 구간 추출을 확인했습니다.
유료 Gemini 호출과 실제 6시간 강의의 분석 품질 검증은 API 키 등록 후 가능합니다.
