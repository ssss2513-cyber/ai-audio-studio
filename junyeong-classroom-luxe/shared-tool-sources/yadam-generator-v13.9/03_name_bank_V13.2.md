# name_bank V13.2 — 조선 야담 인물명·호칭·영문 태그 뱅크

이 파일은 `01_야담_대본_프롬프트_V13.3.7_하이브리드.md`의 작명 보조 자료다. 이름은 역사 논문용 고증 목록이 아니라, 조선 야담에서 신분과 역할이 쉽게 읽히도록 정리한 창작 후보군이다.

## 1. 선택 원칙

1. 인물의 신분·성별·역할에 맞는 구역에서 후보 6개를 내부 추출한 뒤 가장 자연스러운 1개를 고른다.
2. 최근 작품 최대 5편에서 사용한 이름·호칭·영문 태그는 제외한다. 자료가 없으면 현재 작품 안에서 첫음절과 끝음절이 겹치지 않게 한다.
3. 주요 인물은 서로 비슷하게 들리는 이름을 쓰지 않는다. 예: `명주/명월`, `만복/원복` 동시 사용 금지.
4. 사대부 여성은 이름보다 `윤씨 부인`, `최씨 낭자`, `연안댁` 같은 성씨·호칭을 우선한다. 왕실 인물은 휘 대신 직책으로 부른다.
5. 하인·평민 이름을 희화화하거나 신분 비하용으로 쓰지 않는다.
6. 모든 주요 인물은 `한글 표시명 / @english_tag` 쌍으로 고정한다. 태그는 소문자 영문자·숫자·밑줄만 사용한다.
7. 영상 프롬프트에서는 한글 이름 대신 영문 태그를 먼저 쓴다. 예: `@okryeon reaches for the sealed ledger.`

## 13. 새 이름 생성 규칙

후보가 모두 최근 작품과 겹칠 때만 새 이름을 만든다.

- 평민 여성 첫음절: `금, 옥, 명, 월, 매, 복, 덕, 계, 귀, 난, 정, 숙`
- 평민 여성 끝음절: `례, 옥, 순, 임, 실, 심, 선, 화, 월, 향`
- 평민 남성 첫음절: `만, 덕, 재, 성, 봉, 기, 명, 원, 태, 수, 복, 귀, 천, 희, 계, 운`
- 평민 남성 끝음절: `복, 문, 춘, 칠, 수, 백, 길, 만, 동, 학, 겸, 석`
- 사대부 남성 첫음절: `윤, 성, 문, 규, 태, 원, 세, 정, 민, 현, 재, 인, 경`
- 사대부 남성 끝음절: `겸, 헌, 윤, 석, 문, 륜, 찬`

조합 뒤 기존 인물·금지 이름·현대 유명인과 충돌하는지 확인한다. 낯설거나 희화화되어 들리면 사용하지 않는다. 영문 태그는 발음을 단순 로마자로 옮기되 작품 안에서 한 번 정한 철자를 끝까지 유지한다.

## 14. 최종 작명 검증

- 주요 인물 전원에게 고유한 한글 표시명과 영문 태그가 있는가.
- 영문 태그가 `@[a-z][a-z0-9_]*` 형식인가.
- 최근 작품과 이름이 겹치지 않는가. 자료가 없으면 현재 작품 안에서 소리가 뚜렷이 다른가.
- 신분과 호칭이 맞으며, 사대부 여성·관아 인물의 부름말이 장면마다 바뀌지 않는가.
- 악역에게만 우스운 이름을 주거나 하층 인물 이름을 비하 장치로 쓰지 않았는가.
- 인트로와 본편의 태그 철자가 완전히 같은가.
